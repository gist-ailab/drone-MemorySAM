MemorySAM · ReliaDINO · 2026-09-30 기준

ReliaDINO: 외부 레이블 없이, 학습 설계로 센서 의존도를 바꾸는 멀티센서 분할 모델

RGB·Depth·Event·LiDAR 네 센서를 하나의 동결 백본으로 읽고 교차 모달 attention 으로 합친다. 기존 강자(DGFusion·CAFuser)가 조건 텍스트와 depth 정답 같은 외부 신호로 융합을 조절하는 것과 달리, 이 모델은 외부 신호를 쓰지 않고 학습 때 센서를 없애고, 망가뜨리고, 틀리게 만들어 네트워크가 스스로 다른 센서를 찾아 쓰게 한다.

기존 구조의 문제, 우리 방법, 그 원리

세 갈래의 기존 융합 구조가 각각 어디서 막히는지를 우리 실측으로 짚고, 그 막힘에 하나씩 대응하는 설계와 그 설계가 통할 수밖에 없는 이유를 적는다. 근거는 모두 이 프로젝트가 직접 잰 값이다.

원리 ① 의존도는 손실이 만든다

구조를 그대로 두고 학습 표본만 바꾼 Q2 가 event 단독 8.6 → 31.0, LiDAR 단독 4.9 → 22.9 로 올렸다. 반대로 구조에 신뢰도 prior 를 넣은 시도(attention bias 4세대, 품질 헤드 Q3, 무감독 게이트 P55)는 전부 효과가 없었다. 네트워크는 "믿으라"는 신호가 아니라 "이 센서 없이도 맞혀야 한다"는 손실에 반응한다.

원리 ② 대칭이 강건성의 전제다

RGB 를 주인으로 둔 구조(MM SAM-adapter)는 RGB 결측을 정의할 수 없고, depth 정답에 기댄 구조(DGFusion)는 depth 가 빠지면 23~37 을 잃는다. 우리 대칭 융합은 어느 센서가 빠져도 같은 그래프로 동작하며, 그래서 결측·열화 학습이 먹힌다. 대칭이 clean 에서 손해라는 그들의 ablation 은 맞을 수 있다. 우리는 그 대가를 학습 유인(Q2)으로 되갚았다(clean 24클래스 +0.41).

원리 ③ 인식은 센서 자체 신호에서

합성 열화 라벨로 배운 품질 헤드는 실제 야간을 "깨끗하다"고 판정했다(AUROC 0.002). 반면 얕은 블록 특징에는 야간이 선형으로 분리돼 있다(AUROC 0.99). 즉 정보는 있고, 라벨이 틀렸다. 그래서 B 는 센서가 잰 거리를, C 는 얕은 블록 통계를 입력으로 쓰고, 목표는 라벨이 아니라 분할 손실에서 온다.

원리 ④·⑤ 바탕 보존, 계산 조건화

성능의 원천은 동결 백본 + 센서별 LoRA 였다(P34 판정). 그 위에 "얼마나 믿을지"를 따로 계산해 곱하는 길은 오라클 여유 자체가 1.1~1.8 로 작아 막혀 있다. 남은 길은 attention 과 어댑터의 계산이 센서 상태에 따라 달라지게 하는 것이고, 이것이 B·C 의 자리다. 이 두 카드가 통과해야 "modality-aware 구조"를 주장할 수 있다.

MM SAM-adapter(2509.10408)와 무엇이 다른가

주장할 수 있는 것

  • 주 센서 없는 전 센서 융합의 강건성. RGB 가 없거나 틀려도 같은 그래프로 동작하며(Q2: RGB 결측 시 depth 만으로 46.0), 그들의 구조는 RGB 결측을 정의조차 못 한다. DGFusion 에 대해서는 같은 프로토콜로 우위를 확인했고(결측 15조합 48.1 vs 45.5, clean 손해 없음 vs −0.9), MM SAM-adapter 는 같은 조건으로 재어야 성립한다.
  • 백본 동결 + 센서별 LoRA 로 같은 급 성능. ViT-L 미세 조정 없이 val 69.5(그들 69.6), 학습 파라미터 5,900만. 효율·망각 방지 축.
  • 센서 3개 이상. 그들이 한계로 밝힌 지점. MCubeS 4모달 58.07 은 그들에게 비교 대상이 없다.
  • 학습 설계로 만든 상황별 의존도 이동(P56-A 결과 시). 그들의 "필요할 때만 보조 센서 사용"은 RGB-hard 분할 결과로만 보였고, 우리는 조건별 센서 제거 표로 정량화한다.

주장할 수 없는 것 (지금 수치로)

  • DELIVER test·MUSES test 의 절대 1위. 그들이 test 에서 +1.1(DELIVER)·+1.3(MUSES) 앞선다. 우리 1위 주장은 "같은 모달 집합(전 모달)을 쓰는 방법 중"과 val·MCubeS 에 한정된다.
  • "외부 레이블 없음"을 차별점으로. 그들도 쓰지 않는다. 차별점은 DGFusion·CAFuser 에 대해서만 유효하다.
  • "대칭이 비대칭보다 낫다"를 일반 명제로. 그들의 ablation 은 clean test 에서 반대다. 우리는 강건 축에서만 뒤집을 수 있다.

그들의 MUSES test 81.07(RGB+LiDAR 2모달)은 이 문서의 상단 표(MUSES 1차 비교 상대 DGFusion 79.5)에 아직 반영되지 않았다. 우리 규칙상 2모달 방법은 "2차(적은 모달) 비교" 열에 속하며, 그 열의 1위는 GtA 82.39(카메라 단독)라 표의 값은 바뀌지 않지만, 융합 방법이 우리보다 높다는 사실은 논문에서 숨길 수 없다.

왜 이렇게 만들었나

각 설계는 실측 결과 하나에 대응한다. 버린 대안도 같은 기준으로 측정해서 버렸다.

결정근거가 된 실측버린 대안과 그 결과
융합 위에 게이트를 얹지 않는다 창마다 가장 좋은 센서 조합을 고르는 오라클도 전 센서를 다 쓰는 것보다 1.1~1.8 mIoU 밖에 높지 않다(맑음 1.09, 야간 1.43, 안개 1.83). 게이트가 얻을 수 있는 몫 자체가 작다. 합성 열화 라벨로 학습한 품질 헤드: clean −1.31, 실제 야간을 가장 깨끗하다고 판정(AUROC 0.002).

Depth 과의존은 구조가 아니라 clean 학습의 성질이고, 그것을 푼 것은 학습이다. 외부 신호가 없는 우리 E1 도 clean 으로만 배우면 DGFusion 과 똑같이 Depth 가 빠질 때 24~39 를 잃는다(합성 depth 가 완벽해서 거기에 기댄다). 구조를 그대로 두고 두 패스로 학습한 Q2 는 같은 상황에서 4~13 만 잃는다. 야간에 RGB 의존이 줄어드는 이동은 세 모델 모두에 있어 특정 구조의 공로가 아니다(E1 45%, Q2 40%, DGFusion 6% 감소).

두 행은 측정 분할이 다르다(DGFusion 은 test 1897장, 우리는 val 2005장). 같은 test 분할 측정이 진행 중이며, 그 결과가 나오기 전까지 이 표는 방향만 보여 준다.

노벨티

주장의 중심은 하나다. 센서 신뢰도를 알려 주는 외부 신호나 별도 품질 추정기 없이, 학습 표본의 설계만으로 상황에 맞는 센서 의존을 만든다. 이를 세 갈래로 나눠 검증한다.

A · 학습 중

모달 충돌 학습

기존 강건 학습은 센서가 없어지거나 흐려지는 상황을 가르친다. 여기에 한 센서가 선명하지만 틀린 내용을 보여 주는 상황을 더한다. 반사광, 다른 장면의 잔상 같은 경우다. 정답은 나머지 센서가 본 장면이므로, 모델은 센서 간 불일치를 보고 어느 쪽을 믿을지 스스로 배워야 한다.

  • 통과 기준: clean 24클래스 −0.3 이내
  • 그리고 실제 과노출·저노출·모션블러 mIoU 평균 +1.0 이상, 또는 RGB 부분 결측 저하 20% 이상 감소
  • 2시드 평균으로 판정, 첫 결과는 10월 3일 예상
B · 학습 중 (2시드)

거리 조건화 attention

Depth 와 LiDAR 는 값 자체가 거리다. 이 거리값을 교차 모달 attention 의 위치 정보로 넣어, 같은 거리대의 토큰끼리 더 잘 찾도록 한다. 센서가 이미 재고 있는 물리량이므로 외부 레이블이 아니다.

  • 겨냥하는 약점: 먼 거리의 얇은 객체
  • depth 경계 신호, 연결 성분 손실, 세부 가지가 모두 실패한 자리
C · 학습 중 (2시드)

환경 조건 LoRA 전문가 혼합

센서별 LoRA 와 전 센서 공유 LoRA 를 함께 두고, 얕은 블록의 통계로 토큰마다 섞는 비율을 정한다. 공유 LoRA 는 Depth 열화에 강하고 센서별 LoRA 는 clean 에 강하다는 실측에서 출발한다.

  • 얕은 블록이 저수준 변화를 담는다는 프로브 결과

아직 확인되지 않은 것

  • DGFusion 은 공개 공식 가중치(clean test 56.73, 게시값 재현)와 열화 입력으로 재학습한 판 두 가지를 같은 프로토콜로 쟀고(2026-10-01), Q2 가 결측 조합·depth 부분 열화·노이즈 축에서 앞선다. 재학습판은 단일 런이고, 정정(2026-10-02): 재학습판의 열화는 단계적 커리큘럼이 아니라 학습 내내 최대 강도였다(워커 프로세스가 커리큘럼 단계를 받지 못한 코드 결함). 즉 우리 Q2(0.3→0.6→1.0 커리큘럼)와 "같은 커리큘럼" 비교가 아니라 "열화 학습 기준선(최대 강도)" 대비 비교다. CAFuser 도 같은 방식(최대 강도 열화 재학습, 단일 런)으로 쟀다(2026-10-04, clean 55.79): Q2 는 결측 조합·depth 부분·노이즈 축에서 앞서지만 RGB 부분 열화 축은 동률이다. 따라서 주장은 "모든 축 우위" 가 아니라 "결측·depth·노이즈 축 우위" 다. MM SAM-adapter 는 아직 재지 않았다.
  • DELIVER test 와 MUSES test 의 clean 성능은 기존 1위와 평균 기준으로 0.2~0.5 낮다. 1위 주장은 DELIVER val 과 MCubeS 에서만 가능하다.
  • 강건성 수치는 40에폭 스크린 모델 기준이다. 헤드라인 모델(200에폭)에 같은 학습을 적용한 결과는 아직 없다.
  • A · B · C 의 최근접 선행 연구 조사가 끝나지 않았다. 조사에서 나온 2026년 논문 식별자는 원문 확인 전이다.
  • A · B · C 는 학습 중이라 효과를 아직 모른다. A 의 첫 완주는 10-03, B·C 는 그 뒤다. 중간 에폭 수치는 판정에 쓰지 않는다.
  • 같은 구조를 센서 2개로만 학습한 40에폭 스크린(2026-10-02, 시드 1개): RGB+Depth test 56.56 은 4모달 같은 스크린 55.94 와 동률(24클래스 +0.36, 잡음 범위)이고, RGB+LiDAR 55.31·RGB+Event 55.68 은 depth 가 빠지면 지형·건물·초목 클래스가 무너진다. 즉 깨끗한 입력에서는 event·LiDAR 를 더해도 이득이 0 이며, 4모달 구조의 가치는 결측·열화 강건 축에서만 주장한다. MM SAM-adapter RGB-D(57.35)와의 비교는 200에폭 확정 뒤에만 한다.
