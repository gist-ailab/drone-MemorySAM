⚠️ 2026-09-23 생각정리 판정: 이 문서의 "DGFusion 초과"와 얇은4(TrafficSign 포함) 수치는 철회·비정본이다. 정본 얇은4 = Pole·Pedestrian·Static·TrafficLight. 정본 기록은 judgment-ledger 09-23 행.

R1 vs R2 — 같은 병, 다른 처방

P54 결합 카드(R) 후보 · 2026-09-23 기준 · DELIVER 4모달 · 둘 다 E1 스크린 레시피(4탭 TAPS + C3 prototype) 위의 1축(단일 변수) 실험

① 공통 출발점 — 무엇을 고치려나

D6 판정(2026-09-20, 기준선 실패 분석 종합)의 결론: 우리 모델의 결함 축은 "얇고 작고 먼 객체를 찾고도 윤곽을 못 그리는 것"이다. 검출·클래스 지식은 기준선과 같고, 결함은 경계·영역 묘사에 있다.

0.77 ≈ 0.75얇은 객체 찾음률 — 우리 vs 기준선(거의 동일)
0.43 vs 0.25원거리 찾고도 못 그린 비율 — 우리가 2배 나쁨(0.429 vs 0.253)
−0.17원거리 경계 F 격차(TrafficLight) — 멀수록 윤곽이 뭉개짐

면적을 고정해도 거리가 멀수록 격차가 커짐(0.07→0.20→0.43 대 0.05→0.09→0.25) → 해상도·기하 문제이지 클래스 지식 문제가 아니다. 참고로 비슷한 목표의 E17(RGB 합성곱 스템 세부 가지)은 큰 영역만 올리고 얇은 두 클래스는 하락해 축 종결 — "어디에 정보를 보탤 것인가"가 갈림길이었다.

R1과 R2는 이 결함을 정반대 위치에서 공격한다:

  • R1: 표현(특징) 자체에 "경계가 어디다"라는 재료를 준다 — 구조 개입
  • R2: 같은 표현력으로 두고 "얇고 먼 경계를 우선해서 배우게 한다" — 학습 신호 개입

② 개입 위치 — 파이프라인에서 만나는 곳이 다르다

R1은 모델 안(FPN stride-4)에서, R2는 손실 안에서 개입한다 — R2는 모델 구조가 E1과 완전히 동일(state_dict도 동일)해서 바뀌는 게 "무엇을 배우는가"뿐이다. 그래서 두 카드는 직교하며, 둘 다 통과하면 결합 카드(Q3+R)로 합칠 수 있다.

③ R1 — 경계 prior 정제 (BoundaryRefine)

R1 · BOUNDARY_REFINE

베팅: 윤곽이 뭉개지는 건 특징이 "경계가 어디인지" 모르기 때문이다. depth의 불연속(에지) 위치 정보만 주면 특징이 스스로 에지 근처를 선택적으로 갱신할 수 있다.

⚠️ depth를 특징 내용으로 융합하는 축은 이미 반증된 계보(기준선의 depth 과의존과 대비되는 점이 노벨티). 오직 "경계 위치"만 빌려 온다.

① 에지 맵 g = |Sobel(depth HHA)| → 레벨 해상도 축소 → 이미지별 표준화 ② 게이트 e = sigmoid( k·(g − τ) ) # k, τ 학습 가능(초기 k=10, τ=0=평균) ③ 정제 s′ = s + tanh(γ)·Conv3×3([ s ; s⊙e ; e ]) # γ 초기 0.1 (zero-init 금지) # [특징 ; 에지로 게이트된 특징 ; 에지] 를 이어붙여 잔차 생성
  • 파라미터 +118만 개(k·τ·Conv·γ) — 전체 trainable 58.79M → 59.97M
  • 학습·추론이 같은 경로(후처리 아님) — 테스트 타임에도 경계 정보를 씀
  • off 계약: 스위치를 끄면 모듈 자체를 생성하지 않음 → E1과 state_dict byte-동일

④ R2 — 연결 성분 단위 손실 (Component Loss)

R2 · LOSS.COMPONENT

베팅: 문제는 표현력이 아니라 학습 목표의 배분이다. 픽셀 평균 CE는 큰 영역(도로·하늘·건물)이 그래디언트를 독점해서, 얇은 성분의 경계 오차는 묻힌다.

L = CE_OHEM(전체 픽셀) + 0.3 × L_comp L_comp = 1 − Σ w_i · softIoU(pred_i, gt_i) / Σ w_i # GT 연결 성분 i 별, 성분 bbox 국소 계산 w_i = size_w(i) × dist_w(i) size_w = 면적^(−1/2) # 작은 성분일수록 Up dist_w = [1, 1, 1.5, 2, 2] # depth 5분위 [8,47,111,255] — 멀수록 Up (A6 로그 스케일) # 최대 256개 성분, full-res softmax(B=1), 추론 시 비용 0
  • 파라미터 0개 — 모델은 E1과 완전히 동일(total_trainable 58,790,687)
  • 바뀌는 것은 역전파 그래디언트가 작고·먼 성분의 경계로 재분배되는 것뿐
  • depth 구간은 정규화 HHA 텐서를 이미지별 0~255로 근사 복원해 적용(component_loss.py)
