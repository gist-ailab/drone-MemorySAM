# Knowledge distillation for missing-modality robustness in multi-modal learning (focus: multi-modal / multi-sensor semantic segmentation)

Scope note. Verification levels used below: **[PDF]** = I read the method section / equations in the paper text during this session; **[abstract]** = only abstract / listing page read; **[AI-summary]** = only an alphaXiv machine-generated report read (may contain errors); **[unverified]** = not checked in this session. Search date: 2026-11-19.

Target scheme being checked (for reference): frozen teacher of the same architecture trained on clean full-sensor data sees the clean full-sensor input; student sees a copy with sensors randomly zero-filled or synthetically degraded; loss = supervised loss + KL(student logits ‖ teacher logits).

---

## Q1. In multi-modal semantic segmentation benchmarks (DELIVER, MCubeS, MUSES, NYUv2, MFNet, ...), which papers use full-modality-teacher → missing-modality-student distillation?

### Takeaway
The structure "frozen teacher pretrained on full modalities + student trained with random modality dropout + CE + KL on logits" is not only published in this exact benchmark family (AnySeg 2024; RMMSS/RobustSeg 2025-2026; MMANet CVPR 2023; M3L 2023; FuseAdapt NeurIPS 2026) but is explicitly described by RMMSS as the *pre-existing baseline* ("the initial self-distillation and modality masking framework", Eq. 3: L_origin = L_CE + λ L_KL) and is reported as a plain "Output KD" control row by FuseAdapt. The plain logit-KD version is therefore a known baseline in multi-modal semantic segmentation, not a novel contribution by itself.

So the "CE + logit KL from frozen full-modality teacher with random modality dropout" configuration is an explicit ablation row there. — [AnySeg, arXiv 2411.17141](https://arxiv.org/abs/2411.17141)
- AnySeg authors: Xu Zheng, Haiwei Xue, Jialei Chen, Yibo Yan, Lutao Jiang, Yuanhuiyi Lyu, Kailun Yang, Linfeng Zhang, Xuming Hu. It calls itself "the first framework for learning robust anymodal segmentors". — [AnySeg, arXiv 2411.17141](https://arxiv.org/abs/2411.17141)
- RMMSS [PDF], abstract: "current MMSS methods typically use self-distillation with modality dropout to improve robustness". - RMMSS related-work statement that covers degradation as well as masking [PDF]: "In self-distillation, perturbations such as modality masking and noisy inputs are introduced during student training, while a full-modality teacher model is used to guide the student toward correct learning (Zhou et al. 2023; Shin et al. 2024; Hou et al. 2024). ... However, this kind of framework will encounter the problem of performance degradation in the full-modality." — [RMMSS, arXiv 2505.12861](https://arxiv.org/abs/2505.12861)
- RMMSS "basic" baseline row [PDF]: Table 4 (CMNeXt backbone, two-stage self-distillation baseline using Eq.3): Basic = EMM 43.45 / RMM 51.69 / Full 57.50; + HPDM = 47.45 / 53.20 / 57.46; + FSM = 47.94 / 53.63 / 59.89. ### Inferences
- The target scheme minus the synthetic-degradation part is equal to (a) AnySeg's "L_sup + λ L_mad" ablation row, (b) RMMSS's Eq.3 "basic" loss, and (c) FuseAdapt's "Output KD" control (EMA instead of frozen teacher). Three independent places in the DELIVER/MUSES/MCubeS literature present it as a baseline. A reviewer familiar with this line would recognise it immediately, which is consistent with the professor's remark.
- What existing segmentation papers treat as the novel part is always something added on top of logit KD: feature/relation/prototype distillation (AnySeg, RMMSS, MMANet), a second teacher or feedback stage (RMMSS, RobustSeg), or latent prediction of the missing sensor (FuseAdapt).
- Known side effect recorded in this literature: plain full→missing self-distillation lowers full-modality accuracy (RMMSS: 61.92 → 60.45 after stage 1; AnySeg −2.51 mIoU on M-SegFormer as reported by RMMSS). A new paper using the plain scheme would be expected to report the full-modality number alongside.
- Zero-filling at the *input* is the standard evaluation protocol (benchmark 2503.18445) but training-time removal differs by paper: dropped from batch (AnySeg), zero feature map after encoder (MMANet), learnable token (M3L, CRM), routing mask (FuseAdapt). Input zero-fill during training is therefore a minor variation, not a distinguishing feature.
- Combining modality removal with synthetic degradation of the remaining sensors in the student branch was not found as a headline design in the segmentation papers read here; RMMSS's related work nevertheless describes "modality masking and noisy inputs" as known student perturbations in self-distillation. This degradation part is the only component with any room for distinction, and it is covered by another researcher.

## Q2. Outside segmentation: the classical missing-modality distillation line (earliest representative works and years)

### Takeaway
Full-modality-teacher → reduced-modality-student distillation goes back to 2015-2016 (generalized distillation / privileged information, modality hallucination) and has been standard in medical missing-MRI segmentation since 2020 (KD-Net, ACN, then ProtoKD, M3AE). It is also established in action recognition and emotion/sentiment recognition, and a 2024 survey treats it as a standard category.

### Cited Findings
- Lopez-Paz et al., "Unifying Distillation and Privileged Information" (arXiv 1511.03643, ICLR 2016): merges distillation and learning using privileged information into "generalized distillation". — [mlanthology ICLR 2016](https://mlanthology.org/iclr/2016/lopezpaz2016iclr-unifying)
- Hoffman, Gupta, Darrell, "Learning with Side Information through Modality Hallucination" (CVPR 2016, pp. 826–834, DOI 10.1109/CVPR.2016.96): a hallucination network is taught to mimic mid-level features of a depth network so that an RGB-only detector benefits; NYUDv2 object detection. — [CVF open access](https://openaccess.thecvf.com/content_cvpr_2016/html/Hoffman_Learning_With_Side_CVPR_2016_paper.html)
- Garcia, Morerio, Murino, "Modality Distillation with Multiple Stream Networks for Action Recognition" (arXiv 1806.07110, 2018): hallucination network imitating depth features from RGB using soft labels, hard labels and feature distances; NTU RGB+D; framed as generalized distillation. Follow-up with adversarial learning: arXiv 1810.08437. — [arXiv 1806.07110](https://arxiv.org/html/1806.07110); [arXiv 1810.08437](https://arxiv.org/pdf/1810.08437)
- KD-Net, Hu et al., "Knowledge distillation from multi-modal to mono-modal segmentation networks" (MICCAI 2020, arXiv 2106.09564): trained multi-modal teacher → mono-modal student; "The student network is trained on a subset (1 modality) of the teacher's inputs (n modalities)"; teacher trained first with GT loss, then student trained with KL loss + KD loss + GT loss; BraTS 2018. — [arXiv 2106.09564](https://arxiv.org/abs/2106.09564)
- ACN, Wang et al., "Adversarial Co-training Network for Brain Tumor Segmentation with Missing Modalities" (arXiv 2106.14591, June 2021): one model per missing-modality case, co-trained full-modal and missing-modal paths with entropy and knowledge adversarial learning modules; BraTS 2018. Venue is reported inconsistently by secondary sources (MICCAI vs AAAI). — [arXiv 2106.14591](https://arxiv.org/abs/2106.14591)
- ProtoKD, Wang et al., "Prototype Knowledge Distillation for Medical Segmentation with Missing Modality" (ICASSP 2023, arXiv 2303.09830): distils pixel-wise knowledge and intra-/inter-class feature variations from multi-modality to single-modality; BraTS. — [arXiv 2303.09830](https://arxiv.org/abs/2303.09830)
- M3AE, Liu et al. (arXiv 2303.05302) [AI-summary]: single 3D U-Net; modality dropout + patch masking pretraining; a learned substitute image (model inversion) fills missing modalities instead of zeros; fine-tuning with "heterogeneous missing-modal self distillation" within one network; BraTS 2018/2020. Its review groups ACN and SMU-Net as "dedicated" co-training methods that distil from a full-modal teacher to missing-modal students. — [M3AE, arXiv 2303.05302](https://arxiv.org/abs/2303.05302)
- Learnable Cross-modal Knowledge Distillation for multi-modal learning with missing modality (Wang et al., MICCAI 2023) is cited by AnySeg as prior missing-modality KD. — [AnySeg reference list, arXiv 2411.17141](https://arxiv.org/abs/2411.17141)
- Recent medical follow-ups surfaced by search (not read): "No Modality Left Behind: Adapting to Missing Modalities via Knowledge Distillation for Brain Tumor Segmentation" (arXiv 2509.15017); "Bridging the Gap in Missing Modalities: Leveraging Knowledge Distillation and Style Matching" (arXiv 2507.22626); CCSD cross-modal compositional self-distillation (arXiv 2511.14599); multimodal feature distillation with Mamba-Transformer (arXiv 2404.14019). — [2509.15017](https://www.alphaxiv.org/abs/2509.15017); [2507.22626](https://www.alphaxiv.org/abs/2507.22626); [2511.14599](https://www.alphaxiv.org/abs/2511.14599); [2404.14019](https://www.alphaxiv.org/abs/2404.14019)
- Action recognition, KARMMA (arXiv 2504.08578 v3, Feb 2026) [PDF]: two stages; "the trained teacher is frozen and its knowledge is distilled to a lightweight student by aligning the class probability distributions from both models via the Kullback–Leibler (KL) divergence"; L_S = α L_CE + (1−α) L_KL (Eq.4), α=0.7; modality dropout (50%) applied to both teacher and student; missing modalities replaced by learnable tokens; student is smaller (different size); Epic-Kitchens-100, Something-Something V2. It cites Wei et al. [29] as "a multimodal-to-multimodal distillation framework with modality dropout for classification and segmentation" (this is MMANet). — [KARMMA, arXiv 2504.08578](https://arxiv.org/abs/2504.08578)
- Emotion / sentiment: CorrKD (arXiv 2404.16456) transfers cross-sample correlations from a complete-modality model to a student for sentiment analysis with incomplete modalities; arXiv 2608.30563 uses a frozen full-modality teacher's outputs as soft labels for a student in incomplete multimodal emotion recognition (search-result summaries only). — [CorrKD, arXiv 2404.16456](https://www.arxiv.org/pdf/2404.16456); [arXiv 2608.30563](https://arxiv.org/pdf/2608.30563)
- Survey: "Deep Multimodal Learning with Missing Modality: A Survey" (arXiv 2409.07825) describes the general teacher-with-richer-inputs → student-lacking-modalities setup as a category (search-result summary). — [arXiv 2409.07825](https://arxiv.org/pdf/2409.07825)
- Human sensing: "Purify-then-Align: Towards Robust Human Sensing under Modality Missing with Knowledge Distillation from Noisy Multimodal Teacher" (arXiv 2604.05584), listing only. — [alphaXiv 2604.05584](https://www.alphaxiv.org/abs/2604.05584)

### Inferences
- Chronology: 2015-2016 theory and hallucination (privileged modality at training only) → 2018 action recognition → 2020-2021 medical missing-MRI (KD-Net, ACN: one student per subset) → 2023 unified single-model versions with modality dropout (MMANet, M3AE, ProtoKD, M3L, CRM) → 2024-2026 multi-sensor driving segmentation (AnySeg, RMMSS/RobustSeg, FuseAdapt).
- The early works distil to a *fixed* reduced modality set; the 2023+ works use *random* modality dropout with a single student, which is the form the target scheme uses.

## Q3. Do any of these also use a two-pass scheme (clean pass + incomplete pass in the same step)?

### Takeaway
Yes, in two forms. (a) Separate-teacher methods run a full-input teacher forward pass and an incomplete-input student pass on the same sample every step (AnySeg, RMMSS, MMANet, KARMMA with a frozen teacher; M3L, FuseAdapt with an EMA teacher). (b) Single-network self-distillation runs the same weights on the clean and the masked input in one step (CRM, M3AE, UniMRSeg, FuseAdapt's "query without EMA" control).

### Cited Findings
- CRM: one network produces predictions "from clean and masked RGB-thermal pairs" in the same iteration and an L1 loss ties the clean-pair class logits to the masked-pair and single-masked-modality logits (Eq.2-3). — [CRM, arXiv 2303.17386](https://arxiv.org/abs/2303.17386)
- M3AE [AI-summary]: for each subject two different random missing-modal inputs x0 and x1 are generated per step, both get the segmentation loss, and a consistency loss on latent features ties them; this covers full→partial and partial→partial transfer inside one network. — [M3AE, arXiv 2303.05302](https://arxiv.org/abs/2303.05302)
- FuseAdapt Algorithm 1: per step, sample visible set, compute student features and L_seg, "Compute detached target y_t with the full-context EMA teacher", update student, EMA-update teacher. Its control "Query without EMA uses the same query predictor as PMM but a detached online full-context target" (same network, two passes, stop-gradient): 50.59 vs 52.89 with EMA. — [FuseAdapt, arXiv 2610.21779](https://arxiv.org/abs/2610.21779)
- M3L: EMA teacher takes both modalities, student takes the masked input; teacher parameters are detached from the graph; the batch holds labeled samples, a copy of them, and unlabeled samples, with masking applied to the last two thirds. — [M3L, arXiv 2304.10756](https://arxiv.org/abs/2304.10756)
- AnySeg: the same multimodal mini-batch {r, d, l, e} goes to the frozen teacher in full and to the student after random masking (Eq.2-3, Fig.1). — [AnySeg, arXiv 2411.17141](https://arxiv.org/abs/2411.17141)
- RMMSS: stage 1 uses a pretrained full-modality teacher on full input and the student on dropped input; stage 2 runs two frozen teachers plus the student. Reported cost on DELIVER with M-SegFormer: standard training 22 GB / 10 h, stage 1 31 GB / 13 h, stage 2 40 GB / 14 h. — [RMMSS, arXiv 2505.12861](https://arxiv.org/abs/2505.12861)
- AnySeg lists as its limitation "the additional computational cost introduced by the teacher-student framework ... during training". — [AnySeg, arXiv 2411.17141](https://arxiv.org/abs/2411.17141)
- UniMRSeg: two inputs derived from each sample by random modality dropout, with feature-level and prediction-level consistency between complete and incomplete versions during fine-tuning (partially read). — [UniMRSeg, arXiv 2509.16170](https://arxiv.org/abs/2509.16170)

### Inferences
- A clean pass plus an incomplete pass per step is the norm in this literature; the target scheme's frozen-teacher variant matches AnySeg / RMMSS stage 1 / KARMMA exactly in this respect, and the EMA variant matches M3L / FuseAdapt.
- Frozen-teacher vs EMA vs same-network is a known axis; FuseAdapt's ablation gives one data point that an EMA target beats a detached online target (+2.30 mean mIoU on MCubeS) for its latent-prediction objective. No paper read here compares frozen vs EMA teacher for plain logit KD.

### Gaps
- Whether CRM stops gradients through the clean pass is not stated in the pages read.
- M3AE details come from a machine-generated summary; equations were not checked against the PDF.
- No direct frozen-vs-EMA comparison for logit-level full→missing KD was found.

## Conclusion: how established is this structure?

### Takeaway
In multi-modal learning generally, full-modality-teacher → missing-modality-student distillation is a decade-old, survey-level standard technique. In multi-modal semantic segmentation specifically, it has been published since 2023 (MMANet at CVPR 2023, M3L, CRM) and is the dominant robustness recipe on DELIVER / MUSES / MCubeS since late 2024 (AnySeg, RMMSS, RobustSeg CVPR 2026, FuseAdapt NeurIPS 2026); the exact "frozen same-architecture full-modality teacher + modality dropout student + CE + logit KL" form is written down as the baseline in RMMSS Eq.3.

### Cited Findings
- RMMSS abstract: "current MMSS methods typically use self-distillation with modality dropout to improve robustness". — [RMMSS, arXiv 2505.12861](https://arxiv.org/abs/2505.12861)
- FuseAdapt: "Masking, EMA, and teacher–student optimization are established mechanisms". — [FuseAdapt, arXiv 2610.21779](https://arxiv.org/abs/2610.21779)
- MMANet (CVPR 2023): knowledge distillation "is used to transfer the privileged modality information that can only be accessed during the training stage from the teacher to the student" in incomplete multimodal learning. — [MMANet, arXiv 2304.08028](https://arxiv.org/abs/2304.08028)

### Inferences
- Novelty cannot be claimed for the structure itself in multi-sensor semantic segmentation. The closest prior items to cite and differentiate from are: AnySeg (L_mad, Eq.6; Table 3 row "L_sup + λ L_mad"), RMMSS (Eq.3 and Table 4 "Basic" row), FuseAdapt (Table 8 "Output KD"), MMANet, M3L, CRM.
- Elements that the papers read here do not combine in one headline method: (1) joint random sensor removal *and* synthetic per-sensor degradation in the student branch, (2) a strong frozen-foundation-model architecture with the plain logit-KD recipe on DELIVER/MUSES/MCubeS (FuseAdapt does use frozen DINOv2 + LoRA with a full-context EMA teacher, and reports plain output KD as a control, which narrows this gap considerably). Any claim should therefore be positioned as an application/training-recipe detail with honest baselines, not as a new distillation structure.

### Gaps
- The degradation (blur/noise/weather) literature is out of scope here and is needed to judge element (1).
- Coverage is not exhaustive: 3D detection / BEV fusion robustness distillation (e.g. UniDistill, cited by RMMSS) and remote-sensing incomplete-modality segmentation were not surveyed.
