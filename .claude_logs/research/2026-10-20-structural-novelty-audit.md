# 구조 노벨티 감사 (2026-10-20, method "MMSAM | 생각정리", lab-plan DRN-261020-02 / 문제 PRB-DRN-261020-01)

**배경**: user 결정 2026-10-20 "노벨티는 구조에서 찾는다(다 경로)". A2(E1 구조 + Q2 레시피 + 고해상 경로)가 DELIVER test 57.85(2시드)로 DGFusion 56.71 을 넘었으나, 구성요소가 전부 선행 기법이라 논문 노벨티가 비어 있다. 세 축(① Q2 레시피 노벨티 감사 ② "세부↑ 의미 구분↓" 기제 문헌 ③ 멀티센서 세그 미점유 구조 후보)을 서브에이전트 3개로 병렬 조사한 결과를 method 가 교차 검토해 정리한다. 원시 보고는 세 에이전트 산출(이 문서에 표로 옮김). 수치는 각 논문 원문 표·쪽을 에이전트가 조회한 것이며 **method 가 원문을 재확인하지는 않았다**(불확실 등급).

## 0. 한 줄 결론
- Q2 레시피는 **동일 선행은 없으나 부품이 전부 선행에 있어** 방법 노벨티로 세우기 어렵다(§1). 리뷰어 1차 공격은 RobustSeg(CVPR 2026)·FuseAdapt(2610.21779).
- A2 의 남은 실패 세 가지는 문헌상 **두 기제**다(§2): (가) 얇은 두께 잔여 .37 과 야간 넓은 영역 밀림 = 해상도-맥락 트레이드오프의 양끝, (나) TrafficLight FP = 세부 특징을 의미 특징에 **게이트 없이 합산**할 때 맑은 조건에서 의미 경로가 오염되는 현상(MM SAM-adapter 2509.10408 표11 과 조건 일치).
- 미점유 구조 축(§3): 2D 멀티센서 세그에서 **질의 헤드가 센서별 고해상 특징을 직접 읽는 구조는 없다**(CAFuser·DGFusion 은 융합 피라미드만 읽음). 추천 1순위 = S2 "센서별 마스크 임베딩 헤드"(세 벤치 공통, 합산·내적만이라 금지 축과 가장 멂), 2순위 = S1 "희소 센서 전용 stem"(DELIVER·MUSES 한정), 실패 (나)를 직접 겨냥하는 후보 = S5 "세부 경로 피크 유래 소물체 질의 + 물리 크기 임베딩".
- method 종합 제안(§4): **"세부는 어디(where)를, 의미는 무엇(what)을 결정한다 — 센서별로"** 를 한 구조로 묶는다: 고해상 경로를 FPN 에 합산하는 현행 결선(의미 오염의 원인 후보)을 **제거**하고, 센서별 고해상 임베딩을 **마스크 로짓에만** 쓴다(S2). 클래스 로짓은 동결 백본 의미 특징을 읽는 질의가 유지한다. 이것이 기제 (나)의 처방(문헌: 분류는 질의·거친 로짓에 남기고 세부는 경계 결정에만)이고, 기제 (가)에는 센서별 원 해상도 격자 위에서 마스크를 그리는 것이 대응한다.

## 4. method 종합 (교차 검토 뒤 제안, 판정 아님)

§2 의 기제 (나)("게이트 없는 합산이 의미를 오염")와 §3 의 S2 는 같은 처방으로 모인다. 현행 A2 결선은 고해상 경로 출력을 FPN 피라미드에 **합산**하므로, 세부 특징이 클래스 결정(질의 분류·픽셀 디코더)에도 흘러든다. 제안 구조 **"S2-only"**:
1. 고해상 경로 → FPN 합산 결선을 **제거**한다(백본 의미 특징은 오염되지 않음; DINOv3 세그 헤드의 "injector 제거"와 같은 원칙).
2. 센서별 고해상 임베딩 F_s(1/4)는 **마스크 로짓에만** 쓴다: `mask_logit = Σ_s (q W_s)·F_s`. 질의와 클래스 로짓은 현행대로 동결 백본(+LoRA) 의미 특징에서 나온다.
3. 선택: S1(희소 stem)을 F_s 생성 stem 에 적용(DELIVER·MUSES 한정 ablation).
- 주장 문장(초안): "세부는 어디(where)를, 의미는 무엇(what)을 결정한다. 멀티센서에서 '어디'는 센서마다 다르므로, 마스크는 센서별 원 해상도 격자 위에서 그리고 분류는 동결 파운데이션 의미에 남긴다."
- 이 제안이 성립하려면 먼저 **DRN-261020-01(A2 실패-키 분석)의 H1**이 사실로 확인되어야 한다: hires-off 추론으로 TrafficLight FP 가 50% 이상 줄면 "합산 오염"이 원인. H1 이 기각되면(FP 감소 < 20%) 실패 2 는 Q2 레시피 쪽이고, S2 는 실패 1·3 만 겨냥한다.
- 게이트 사전등록은 분석 결과를 받은 뒤 제안서(`decisions/2026-10-xx-s2-sensorwise-mask-head-proposal.md`)에서 한다. 비교 기준선 = A2 같은 시드(s821·s902·s903). 예상 ablation: A2(합산) / S2-only(합산 제거+센서별 마스크) / S2+합산 유지 / S2+S1.
