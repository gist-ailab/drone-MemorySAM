# 노벨티 정산 — 무엇이 작동했고 무엇이 0인가

> **결론 한 줄**: 성능은 **백본 교체(SAM2→DINOv3 frozen) + per-modal LoRA** 에서 나왔고, 우리가 "기여"라 부른 **신뢰도 기반 융합 모듈들은 사실상 전부 ≈0** 이다. 하필 **간판 노벨티인 RBMA additive attn-bias가 정확히 0**.
> 수치의 canonical = repo `.claude_logs/experiments/monitor-log.md`. 이 노트는 **해석**이다.

## 1. 전수 판정

| 제안 모듈 | 판정 | 근거 | 확정도 |
|---|---|---|---|
| **ATTN_BIAS** (= RBMA 간판 노벨티) | **0** | G0c full-res 전체셋 toggle: baseline 68.20/56.64 ≡ strip-full 68.45/56.38 | **확정** |
| **CONSISTENCY** | **0** | 동일 (bias/cons/veto 합산 효과 ≈0) | **확정** |
| VETO | ~0 (gate 있으면 moot) | G0c + D5 | 높음 |
| **GATE + CALIB** | **test +0.26** ← 유일하게 非0 | G0c full-res(off → 56.38, val +0.25 트레이드오프) | **확정** |
| **ROUTER** (P31 포트) | **순이득 +0.10**(노이즈). 단 **의존도는 구조적으로 큼** | P35 vs P36 별도 학습 = val +0.13 / test +0.10 | 높음 |
| **DINOv3 frozen 백본** | **+10~12** (linear probe) | A-1 probe: img probe test 40.5 vs SAM2 28.9 | **확정** |
| **per-modal LoRA** | **lidar Δacc +0.16~0.20** | D3B modal_adaptation | 확정 |

## 2. router의 함정 — "의존"과 "기여"는 다르다

D5 ablation(`test_epoch58`, n=40, 5/5 도메인 일관)에서 `p36_router_off` → **ΔmIoU +38~+42** (mIoU 46.71 → ~4.7 붕괴, Road −93.1). **features는 불변(cos 1.0, shift 0.0)인데 예측만 완전히 바뀜**(agree 0.14) — router가 head 출력에 residual로 붙는 구조와 정합.

**이걸 "router가 +42 기여"로 읽으면 안 된다.** 이 toggle은 **추론 시 의존도**를 잰다. router와 함께 학습된 모델에서 추론 시 router만 빼면 학습된 α≠0인 한 **구조적으로 붕괴**한다. **"도움이 되는가"의 정답은 별도 학습 비교(P35 vs P36) = +0.10.**

→ **load-bearing이지만 value-adding이 아니다.** 모델이 계산을 router 경로로 옮겼을 뿐 정확도는 안 늘었다. **일반 교훈: residual + learned-α 모듈의 inference-time ablation은 기여 측정 도구가 아니다.**

## 3. 방법론 유보 (중요 — 과잉 단정 방지)

- **소표본 ablation은 신호를 놓친다.** n=40/도메인 D5는 gate/calib을 "≈0"으로 봤으나 **G0c full-res 전체셋에서 +0.26 기여로 반전**됐다. 위 표에서 attn_bias/consistency만 full-res 확정이고 나머지는 재검증 여지가 있다.
- D5 대상이 **test-best ckpt**(불법 선정본)라 val-best로 재확인 가치 있음.
- 단 router의 +40은 소표본 문제가 아니라 구조적 의존이라 결론 불변.

## 4. 이게 논문에 뜻하는 것

**현 서사("RBMA = 신뢰도 기반 멀티모달 융합이 기여")는 방어 불가**하다. 리뷰어가 ablation을 요구하면 위 표가 그대로 나오고, **간판 모듈이 0**이다.

**전환 후보 — negative result를 기여로**:
> *"멀티모달 신뢰도 융합 모듈(additive attn-bias / consistency / gate / veto / per-class router)은 **frozen VFM 위에서 효과가 없다**. 실제로 성능을 만든 것은 **백본과 per-modality adapter**다."*

이 주장을 **외부 증거가 강하게 뒷받침한다**:
- **MUSES 리더보드 1위 GtA(82.39)가 카메라 단독**이고, 4모달 융합(DGFusion 79.49 / CAFuser 78.19 / GeminiFusion / CMNeXt)이 **전부 그 아래**다 → 멀티센서 융합이 이기고 있지 않다는 게 **우리만의 관찰이 아니다**.
- 우리 계보의 3세대(P28~P33 SAM2 융합, P34~P36 DINOv3 융합)가 **독립적으로 같은 결론**에 도달했다.

**남은 정직한 자산**:
- **DELIVER test 56.62 = DGFusion 56.71에 −0.09**(사실상 동률)를 **더 적은 감독으로** 달성 — DGFusion은 **GT log-depth 감독 + CLIP 조건 메타텍스트**를 쓰고 우리는 **seg 라벨만** 쓴다.
- **val·test 동시 최상위권은 우리뿐**: val 1위 CAFuser-CAA는 test 55.38, test 1위 DGFusion은 val 66.51 — 전부 트레이드오프에 걸려 있는데 P34만 68.19/56.62.

## 5. 열린 질문

- **radar 미스터리**: MUSES 4모달이 radar 추가만으로 붕괴(ep4 24.42 vs 3모달 68.66). DELIVER는 4모달로 정상 → "4모달 자체"는 원인 아님. 원인 규명 시 **모달 추가가 왜 해로운가**에 대한 증거가 되어 위 negative-result 서사를 강화할 수 있다.
- gate/calib의 +0.26이 **유일한 살아있는 모듈**인데, 이것만으로 기여를 주장할 수 있는가? (규모가 너무 작음)
- val-SOTA 레퍼런스 불일치 미해결: CAFuser README **68.79** vs 우리 문서 **68.6**. 논문 전 정합 필수.
