# P33-v2 설계 개정 (2026-07-08)

> **원안**: P33 CG-MoD (repo `git show fcf3857:.claude_logs/26_p33_design.md`) — C1 competence-gated hard fusion / C2 modality dropout / C3 calibration 복원+gate 승격 / C4 thin-class 강건화.
> **개정 이유**: P32 4축 독립 검증이 원안의 전제 2개를 뒤집었고(misalloc=증상, event/lidar=잉여), 문헌 3축이 설계 디테일 다수를 수정·보강.

---

## 1. 원안 C1~C4 판정 요약

| 모듈 | 판정 | 핵심 변경 |
|---|---|---|
| C1 게이트 | 방향 유지, **3중 수정 + 우선순위 강등** | top-k hard 삭제(Soft MoE/vision-router 증거), entropy 페널티→**hinge/target형**(AECF 붕괴 경고), 기대치 clean +0.3~0.6으로 하향(CAFuser ablation) — 성과·서사는 **adverse-split 기준** |
| C2 드롭아웃 | **강지지**, 단 단독 불충분 | **distillation/unimodal-aux 필수 결합**(AnySeg 소생 실체; MAGIC 단독 실패, M3L "alone is not sufficient"), 80% 단일 / **20% img+depth 동시 drop**, zero-fill 금지(토큰/브랜치 제거) |
| C3 calibration+승격 | 지지, 강화 조건 2 | CoRB attn-bias는 **제거 확정**(유의한 순손해 p=4.5e-22), gate 입력은 반드시 **corr_veto**(순수 corr는 workhorse 파괴 — Phase0 B/C), calibration 복원 시 img AUROC 모니터링 게이트(P31 over-rotate 전례) |
| C4 클래스 전이 | **CONFIRMED + 4순위→1순위 승격** | focal/CB → **RCS**(DAFormer) + **CLIP-text class anchor**(Any2Seg: 같은 벤치 Water +22.3/Wall +6.6) + **MIC식 masked consistency**(night+**sun**); **unfreeze 삭제**(Rein/LP-FT/Surgical-FT 정면 반박) |

### corr_veto 반영 점검 — 명목상 반영, 실질 구멍 3개 (수정 필수)
1. gate 입력은 순수 corr가 아니라 **blend된 corr_veto** (`g·selfent + (1−g)·corr_bc`, `g_i=clamp(selfent_i − max_{j≠i} selfent_j, 0,1)`) 명시.
2. calibration 복원이 selfent 지형을 바꾸므로 **보정된 새 모델 위에서 corr_veto AUROC 재측정**(무학습, 도구 있음) 절차 추가.
3. 학습 게이트가 veto를 무시하도록 배울 수 있음 → **training-free hard floor**(corr_veto 극단 저값 모달의 게이트 상한 clamp)를 게이트 밖에 유지.

### B→A 릴레이 정합성 (브레인스토밍 카드 A/B)
- C1/C2/C3/C4 전 항목 **A-safe**(백본 무관: 예측분포·토큰·데이터/loss 레벨). 유일한 위반 후보(unfreeze)는 삭제됨.
- 게이트 1차 입력은 아키텍처-무관 스칼라(rel_cal, corr_veto)로, feature summary는 옵션 채널로 격리.
- corr_veto 신호 계산은 모델 클래스 밖 유틸로 분리 → 카드 A(DINOv3-RBMA)에 그대로 이식.
- **A-1 probe(DINOv3 frozen, 1 GPU-day)는 P33과 병행 실행** — 릴레이 전환 판단 조기화.

## 2. P33-v2 모듈 (우선순위순)

| # | 모듈 | 내용 | 기대(test pt) |
|---|---|---|---|
| **M0** | 진단 3종 (무학습) | (a) 공개 CMNeXt/StitchFusion ckpt를 우리 per-class **test** 하니스에 통과(벤치마크 천장 판별 — per-class test 표는 어느 논문에도 없음), (b) CoRB-off 추론 확정, (c) 보정모델 위 corr_veto AUROC 재측정 | +0.01 + 방향 확정 |
| **M1** | Class-transfer 복구 (구 C4 승격) | RCS + CLIP-text class anchor(서술형 프롬프트 — CARLA 라벨명 금지) + MIC식 masked consistency(EMA teacher, night+sun); copy-paste 2단계; unfreeze 삭제. 타깃 = **Wall/TrafficLight**(SOTA val 85·84 = headroom 입증), Water/Bridge 과투자 금지(벤치마크 고유 난제: SOTA val 24~46/54) | **+2~4** |
| **M2** | Dropout+Distillation (구 C2 보강) | p 0→0.3(plateau 시 0.5 여지, >0.5 금지), 80% img/depth 중 1 drop + 20% 동시 drop, E/L 미드롭, 토큰/브랜치 제거, unimodal aux head(w 0.1~0.5, MMPareto 경고) 또는 online full-modal KD | **+0.5~1.5** (drop-Δ 양수화) |
| **M3** | Soft Competence Gate (구 C1+C3 통합) | soft gate + τ sharpening + hinge-entropy(floor 초과만 벌점) + batch balance α≤0.01(Switch식) + 입력 [rel_cal, corr_veto, cond-token(CAFuser식)] + veto floor + calibration 복원(img AUROC 게이트) | +0.3~0.6 clean / **+1~2 adverse** |
| **M4** | CoRB attn-bias 제거 | λ=0 기본, config seam은 논문 ablation용 보존 | +0.01 |

**합계 현실 기대: test 55.0 → 56.5~58 (M1 지배) / val 64.1 → 65~66 — 66.51 미달 가능성 → 카드 A 릴레이 트리거.**

## 3. Config seam

`configs/b200-deliver_rgbdel_P33v2_physaug.yaml` (P32 복제 +):
- `CORROBORATION.{ATTN_BIAS: off, CONSUME: gate, SIGNAL: corr_veto}`
- `GATE.{MODE: soft, TAU, ENTROPY_REG: hinge, ENTROPY_FLOOR, BALANCE_ALPHA: 0.01, INPUTS: [rel_cal, corr_veto, cond_token], VETO_FLOOR: on}` (~~TOPK~~ 삭제)
- `MODAL_DROPOUT.{ENABLE, P, WARMUP_EP, TARGETS: [img,depth], DUAL_DROP_FRAC: 0.2, MODE: token}` + `DISTILL.{UNIMODAL_AUX_W, FULLMODAL_KD}`
- `LOSS.RCS.{ENABLE, TEMP}` · `TEXT_ANCHOR.{ENABLE, PROMPTS}` · `CONSISTENCY.{MODE: masked_ema, CONDITIONS: [night,sun]}`
- `CALIBRATION.ENABLE: true` (+ per-modal AUROC 로깅) · ~~UNFREEZE~~ → `LPFT.{ENABLE: false}` (gated ablation 전용)

구현 seam: `semseg/models/sam2/sam2/sam_lora_image_encoder_seg.py` (`_fuse_outputs` / `_compute_bias_source`). P28~P32 byte-identical 관례 유지(전부 config-gated).

## 4. Ablation 4단계 (원안과 순서 역전)

1. **P33.1 = M0+M1**(+calibration) — 게이트: test > P28 **55.27** 및 Wall test IoU >10 · TL >30 (현 0.88/15.4)
2. **P33.2 = +M2** — 게이트: drop-Δ(event)+drop-Δ(lidar) ≥ +1.0, full-modal val 하락 <1.0
3. **P33.3 = +M3** — 게이트: night/fog split +≥0.5 vs P33.2, clean 회귀 ≤0.3, corr_veto AUROC 전 모달 >0.5
4. **P33.4 (조건부) = +copy-paste / LP-FT unfreeze** — P33.1~3 통과 + headroom 잔존 시만

측정 고정: 출처 = 재구조화 브랜치 monitor-log(9501129), aggregate test + per-class test + adverse-split 3종 병기.

## 5. Kill criteria

- **M0-a**: SOTA도 test Wall/TL ≈0~15 → 벤치마크 천장 — M1 타깃 철회·headroom 클래스 재조준 + **카드 A 전환 즉시 상정**
- **M1**: text-anchor 40ep에 타깃 val IoU +1 미만/test 무변화 → 제거; RCS 무이득+다수클래스 −0.5 → 온도 완화 1회 후 제거
- **M2**: dropout+distill 후에도 drop-Δ≈0 → "잉여" 판정 수용, E/L 브랜치 동결·연산 회수
- **M3**: adverse 이득 <0.3 또는 depth-only 붕괴+night 하락(AECF 실패형) → hinge 재튜닝 1회 후 rel-비례 고정 융합으로 회귀
- **Global escape**: P33.2 후 test <55.5 또는 전체 후 val <65.5 → **카드 A(DINOv3-RBMA) 전환**(fusion v2 설계 이식)

## 6. 비용

B200 기준(P32 풀런 ≈3~4 GPU-day): M0 0.5~1 · P33.1~.3 각 4 · P33.4 조건부 4 · A-1 probe 병행 1 · 튜닝 여유 2~3 → **필수 ~15, 조건부 포함 ~20 GPU-day (약 3주)**.

## 7. 원안 대비 결산 + 근거 문헌

- **유지**: C2 방향·p 스케줄·E/L 미드롭, C3 calibration 복원·gate 승격, C1 학습 게이트 개념, config-gated 계보 관례.
- **변경**: ablation 순서 역전(C4→1순위), top-k/단순 entropy → soft+hinge+batch-balance, C2 distillation 필수, C4 focal→RCS+text-anchor+masked-consistency, unfreeze 삭제.
- **폐기 KPI**: misalloc<25%(증상 지표), competence>25(anymodal 천장 17~19 위) → 대체: per-class test IoU(Wall/TL), drop-Δ>+1, adverse-split delta.
- **주요 문헌**: CAFuser(2410.10791, MUSES SOTA·게이트 직접 선례) · Soft MoE(2308.00951)/vision-router(2401.15969) · AECF(2505.15417) · Switch(2101.03961) · AnySeg(2411.17141, DELIVER E/L 소생 17.3/19.0) · MAGIC(2407.11344)/M3L(2304.10756) · MDA-KD(2403.04245) · MMPareto(2405.17730) · OGM-GE(2203.15332) · Any2Seg(2407.11351, per-class val 유일 수치표+text-prior 직격) · DAFormer RCS(2111.14887) · copy-paste(2012.07177) · MIC(2212.01322) · tqdm(2407.09033) · Rein(2312.04265) · LP-FT(2202.10054) · Surgical-FT(2210.11466) · CMNeXt(2303.01480) · GeminiFusion(2406.01210) · DGFusion(2509.09828, test 표).
