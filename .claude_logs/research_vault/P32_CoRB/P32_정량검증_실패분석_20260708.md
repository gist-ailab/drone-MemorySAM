| modal | 단독 competence | reliability | UAMM w | 판정 |

- **핵심 재해석**: event/lidar의 낮은 competence는 "어댑터 실패/정보 부재"가 아니라 **depth와의 잉여(redundancy)** — 이들이 잘하는 클래스(기하 대형)를 depth가 이미 전부 커버해 drop-Δ ≈ 0 (|Δ|≤0.22). 문헌 캘리브레이션: 현 16.9/15.3은 **anymodal SOTA(AnySeg) 소생 후 천장(17.3/19.0) 부근** — "depth급으로 올린다"는 목표 자체가 문헌상 천장 위.
- img<depth의 원인은 야간이 아니라 전 조건 공통(DELIVER 시뮬 특성) — night는 img를 추가로 깎을 뿐.

## 3. 퓨전 + 제안모듈(CoRB) 판정 (A3)

- **UAMM 균일**: 평균 [0.271/0.274/0.229/0.226], 이미지별 std ≤0.016. night에서만 uamm_img 0.256으로 미세 하락(misalloc 51.6%→10.8% 급감) — **방향은 맞으나 진폭(±0.02)이 무력**한 미약 감각.
- **misalloc 재해석 (판정 뒤집힘)**: misalloc=1 이미지가 오히려 mIoU **+6.5pt 높음**(p=2.0e-34; 조건 통제 후 4/5 조건 +3.9~+9.6). uamm top-1 마진이 ±0.01(606장이 |마진|<0.005)이라 top-1 라벨이 무의미 — misalloc은 균일 가중치의 **증상**이지 실측 비용이 아님. **개선 레버 = "argmax 교정"이 아니라 "가중치 진폭 확대(적응화)"**. worst-50의 misalloc률은 28%로 전체의 절반 → 실패 원인 아님(반증).
- **CoRB 순효과**: ΔmIoU(ON−OFF) mean **−0.0133** / median −0.007, flip 0.046%, helped 61 / hurt 136 / neutral 1700. **Wilcoxon p=4.5e-22, 57.8% 이미지에서 음수** — 단순 중립이 아니라 유의한 순손해. rain 최악(−0.024), fog만 helped>hurt. hurt 이미지가 helped보다 쉬운 이미지(57.9 vs 55.0) = 잘 되던 케이스를 건드림.
- **귀속 문제**: P32의 P31 대비 이득(+0.92/+0.15)은 추론시 CoRB를 꺼도 동일하므로 **CoRB 모듈의 직접 기여로 귀속 불가**(학습 dynamics 간접효과 또는 run간 분산).
- 융합 자체는 실패 아님: fused 51.73 = depth 단독 +8.0pt, 98.5% 이미지 우세.

## 4. 실패 케이스 (A4)

- **worst-50** (mIoU 26.2~35.1): 조건 분포 **sun 14 / night 13 / cloud 11** / rain 7 / fog 5 — night 단독 문제가 아님. 연속 stem 군집(cloud 044650~044950, sun 000400~000600 등, 최소 20장이 인접 짝) = **소수 하드 씬**.
- **유형화** (worst-190=하위 10%): (a) 구조물 클래스 소멸형 + (c) 소수클래스 페널티형 복합 = **88%** (a∩c 115장, dead-8클래스 수와 mIoU 상관 −0.695), (b) night 조도형 8장(Truck −24/Cars −19/Vegetation −16), (d) misalloc 동반형 **반증됨**.
- **NEW sun 하드씬**: sun worst에서 Pedestrian −35/GroundRail −36/Truck −32pt. per_class_matrix에서도 Pedestrian(44.7)·SideWalk·Cars 최저 조건 = sun (night 아님). → 증강/consistency 타깃에 night뿐 아니라 **sun/shadow 포함** 필요.
- **per-class 붕괴 확정**: Bridge 전 조건 0(242프레임 전부), Water 99% 프레임 0, Wall 90% 프레임 0(단 night max 86 — all-or-nothing, 완전사망 아님), TrafficLight 49% 프레임 0. **val에선 생존(56/46/33/79)** = 용량이 아니라 전이 문제.

## 5. 원인 지도 (종합 판정)

```
[상류] day-val→test per-class 전이 붕괴 (원인4 CONFIRMED, 지배 원인)
   + img의 전 조건 공통 열세 → depth 단일 workhorse 구조
      ↓
[중류] depth 지배 → event/lidar 잉여화 (원인2 "정보부재"→"잉여"로 수정)
   + UAMM 적응화의 기대이득 압축 (depth 외 대안 빈약)
      ↓
[하류] uniform UAMM (원인1 "misalloc 비용"→"증상"으로 수정) = 미실현 이득
   CoRB attn-bias (원인3 CONFIRMED+악화: 유의한 순손해) = 주입 지점 결함
      ↓
[증상] worst 프레임 = 죽은 클래스 밀집 씬 + sun/night 하드씬 (NEW)
```

**수리 우선순위** (test pt 기대): ① 죽은 클래스 전이 복구 **+2~4** (상한 +7.9) → ② 하드씬 객체 붕괴 +0.5~1.5 → ③ 가중치 적응화 +0.3~1 (adverse-split에서 +1~2) → ④ CoRB attn-bias 제거 +0.01(무비용) → ⑤ event/lidar 소생은 drop-Δ>0 목표로만(+1~3 상한). 상세 설계 = [[../P33_CGMoD/P33_v2_설계개정_20260708|P33-v2]].
