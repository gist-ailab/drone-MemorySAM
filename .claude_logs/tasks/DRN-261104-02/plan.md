# 고해상 경로 특징 수준 시각화(학습 0): FPN s4 에서 고해상 경로가 더하는 것이 얇은 구조인지 — 같은 A2 ckpt 로 피라미드 세 공급원(SimpleFPN·탭·고해상) 분리 + 추론 시 끄기 짝 비교 + 얇은 클래스 화소 집중도

- id: DRN-261104-02
- kind: analysis
- 문제(PRB): -
- 질문: 논문 Fig.(고해상 경로)로 '세부는 고해상 경로에서만 온다'를 특징 수준에서 보일 수 있는가: 같은 학습된 A2 에서 FPN s4 에 더해지는 세 공급원을 따로 그렸을 때 얇은 구조(Pole·TrafficLight·Pedestrian·Static 경계)가 고해상 경로 출력에만 나타나고, 그 에너지가 얇은 클래스 화소에 집중되는가
- 가설: H-V1: 고해상 경로 출력 s4 의 채널 노름이 얇은 4클래스 GT 화소에서 그 외 화소보다 ≥1.5배 높다(SimpleFPN s4·탭 s4 는 <1.2배). H-V2: 같은 ckpt 로 추론 시 고해상 경로만 끄면(hires_infer_mode off) 얇은 4클래스 IoU 가 다른 20클래스보다 크게 떨어진다(얇은 4 평균 Δ 가 나머지 평균 Δ 의 2배 이상)
- 바꾼 변수(change): 학습 없음. 입력은 논문 모델 A2 s821 ckpt 하나(NAS ckpts/a2_s821_20261016_073952/). 비교 변수 = 피라미드 공급원(세 개 분리)과 hires_infer_mode on/off
- 기준선: 같은 ckpt 의 SimpleFPN s4·탭 s4(공급원 대조) + Q2 s821(고해상 경로 없이 학습한 짝)의 s4 — Q2 는 '학습부터 없던 경우'의 참고 행
- 성공 기준: 채택 = H-V1·H-V2 둘 다 충족 → 원고 Fig.(고해상 경로)에 패널 (a)입력 (b)SimpleFPN s4 (c)탭 s4 (d)고해상 s4 (e)합 (f)on/off 예측 을 넣고 본문에 집중도 비율·on/off 얇은 Δ 를 적는다. 하나만 충족이면 충족한 쪽만 그림으로, 둘 다 미충족이면 '고해상 경로 이득의 특징 수준 근거 없음' 으로 한계에 적는다
- 반증 조건: H-V1 비율 <1.2 이거나 H-V2 에서 얇은 4 Δ 가 나머지 Δ 와 같은 수준(2배 미만)이면 '고해상 경로가 얇은 구조를 공급한다'는 서술을 철회하고 이득 원인을 미확인으로 둔다
