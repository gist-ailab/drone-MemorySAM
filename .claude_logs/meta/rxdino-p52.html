RxDINO — 자기-적응 처방 멀티모달 세그멘테이션

2026-09-01 · 개정 확정판(단일-config) · 근거 = 원장 H1~H22 + 개정문서 decisions/2026-08-31-p52-rxdino-adaptive-amendment.md

한 줄 정의 — 하나의 미니멀 frozen-VFM 아키텍처(추론 그래프 3벤치 동일) 위에서, 학습 중 계산되는 병리 지표가 학습-전용 처방의 강도를 스스로 조절한다(클래스축 C3-adaptive · 모달축 UniBal-adaptive). 벤치별 config 차이 0 — 데이터셋별 거동은 λ 궤적으로 창발한다. 초기화는 500k pseudo-모달 정렬 사전학습(P50).

1. Motivation — 왜 이 구조인가 (소거가 설계를 도출)

이 구조는 취향이 아니라 3주 캠페인(가설 22개, 통제 실측)의 소거 결과다. 각 설계 결정이 어떤 반증/확인에서 나왔는지:

관찰 (실측)결론설계 귀결
백본 교체(SAM2→DINOv3)가 계보 최대 단일 변수 +11.6 (H6) · L 초과 스케일은 +0.18 포화 (H12)표현력이 지배하되 L에서 충분frozen DINOv3-L 고정, 백본 학습 안 함
믹서 4갈래 전부 무익: 선택/라우팅(H16, anti-consensus) · cross-attn −2.05 (H17) · 산술평균과 동급 (H21) · 저랭크 결합 −0.82 (H19)믹서는 병목이 아니다 — 정교화는 무익~유해융합부를 의도적으로 미니멀하게 (gated-MLP 유지, 정교 융합 모듈 배제)
lidar 유효랭크 4.7 붕괴 → VICReg으로 78+ 복원, MUSES +0.76 (트렁크와 묶음)표현 붕괴는 학습 정칙화로 고쳐진다VICReg 정칙화 유지 (N7 격리 측정 중)
C3 고정 적용: DELIVER +1.4 / MUSES −0.77 / MCubeS 표적만 회복 — 효과가 병리 강도에 단조 (H20, 사전등록 예측 2/2 적중)처방은 병리 있는 곳에만 — 단 사람이 벤치별로 켜고 끄면 단일 메서드가 아님 (user 지적)처방 강도를 온라인 지표의 함수로 — 오프라인 진단 폐기, 컨트롤러로 전환
MUSES 4모달<3모달, radar drop +0.13 = modality laziness / DELIVER는 2모달 학습 시 −2.85(laziness 없음)모달축 병리도 벤치별로 있고 없다UniBal도 adaptive로 — 게으른 모달만 자동 감독
어댑터는 타깃 3~4천 장 from-scratch였음 → 정렬 사전학습 +0.74~+1.38 (H22, 매칭 통제)정보 축(초기화)이 실제로 열려 있는 유일한 축P50 정렬-사전학습 init 채택 (500k, 어댑터만)

3. 블록별 상세

3.1 입력 — 모달리티 스택

항목내용
구성데이터셋 제공 센서 전부 사용: DELIVER = RGB·Depth·Event·LiDAR / MUSES = RGB·LiDAR·Event·Radar / MCubeS = RGB·AoLP·DoLP·NIR. 각 모달 3채널 정규화 후 동일 해상도(학습 768², 평가 1024²/native)
설계 이유모달 선택도 "설정"이 되지 않도록 전부 투입 — 어떤 모달을 얼마나 쓸지는 UniBal-adaptive와 융합이 학습으로 정함

3.2 공유 frozen 백본 + 모달별 LoRA

항목내용
백본DINOv3-L ViT (24블록, dim 1024, patch 16) — 완전 동결(304M). 모든 모달이 같은 백본을 통과
LoRA각 attention의 fused-qkv에서 Q·V에만 모달별 저랭크 어댑터(r=16): y_q += B_q^(m) A_q^(m) x. 모달 m은 forward마다 선택 — "하나의 눈, 모달별 보정 렌즈"
왜 frozen인가백본 교체가 +11.6(H6)으로 지배 변수였고, L 초과 스케일은 포화(H12) — 표현력은 사오되(pretrained) 파괴하지 않는다(fine-tune 시 붕괴 위험). 학습 파라미터 ~50M로 4090 학습 가능
출력모달별 토큰맵 M × (B, N, 1024) @ stride16

3.3 융합 트렁크 — 의도적으로 미니멀

항목내용
구조gated-MLP: fused = Σ_m γ_m ⊙ MLP(z_m), γ = tanh(0.1) init(gradient 즉시 흐름 — zero-init 5연속 사망의 교훈, 원장 키1)
VICReg모달별 토큰에 variance(차원별 최소분산 유지) + covariance(차원 간 탈상관) 항 — lidar 유효랭크 4.7→78+ 복원 실측. 학습 전용
왜 미니멀인가믹서 4갈래 통제 소거(선택 H16·attn H17·평균 H21·결합 H19)가 "정교한 융합은 무익~유해"를 실측 — 남은 보완정보는 anti-consensus(합의·신뢰도·결합 어느 신호로도 접근 불가)라 믹서가 아니라 학습신호·초기화로 승부한다는 것이 이 모델의 핵심 주장

3.4 디코더

항목내용
SimpleFPN단일 stride-16 맵에서 ViTDet 방식으로 4스케일(4/8/16/32) 피라미드 생성 → lateral conv 256ch
픽셀 헤드FPN 융합 → per-pixel 분류 (클래스 수는 데이터셋에서 자동)
M2F-lite auxMask2Former-lite 보조 손실(deep supervision) — 학습 전용, 추론 시 미사용

3.5 C3-adaptive 컨트롤러 (클래스축 처방) 구현·스모크 검증 완료

항목내용
병리class-transfer 붕괴: 희소 클래스의 픽셀이 지배 클래스로 통째 흡수(예: DELIVER RailTrack IoU 4 — 대부분 Road로 예측)
지표 (온라인)train 배치 argmax 혼동의 EMA M(C×C)에서 s_c = (1−recall_c) × conc_c, conc_c = 최다 혼동상대 집중도. "그냥 어려운" 클래스(오답 분산)와 "흡수되는" 클래스(오답 집중)를 구분
처방λ_c = λ_max·clip(s_c/τ) 로 per-class 가중 prototype 손실 — 붕괴 클래스 특징만 자기 클래스 EMA prototype으로 당김. 건강 클래스는 압력 0. 전 클래스 붕괴 시 현행 균일 λ와 동일(고정팔이 상한의 특수 케이스)
근거 실측고정팔 dose-response(H20, 예측 2/2 적중): 붕괴 심함→+1.4(RailTrack 4→68) / 없음→−0.77 / 중간→표적만 +9.76(rubber)

3.6 UniBal-adaptive 컨트롤러 (모달축 처방) 구현·스모크 검증 완료

항목내용
병리modality laziness: 융합 손실만으로 학습 시 강한 모달(RGB)이 gradient를 지배 → 약한 모달 인코더가 안 배워진 채 무임승차 → 모달 추가가 오히려 손해(MUSES 4모달<3모달)
지표 (온라인)모달별 보조 head(GN→1×1)의 uni-modal CE 손실 L_m의 EMA → g_m = clip(L_m/mean−1, 0, cap): "혼자서 유난히 못 푸는" 모달 = 게으른 모달
처방λ_u,m = λ_u_max·g_m/cap 로 그 모달에만 uni-modal CE 강화 — "radar도 혼자 세그를 시도하라"는 개인 숙제. head는 학습 후 폐기
선례학습-내 모달 기여 측정→변조는 OGM-GE(CVPR'22) 계열로 검증된 언어 — 우리 차별점은 클래스축과 함께 "자기-진단 처방" 단일 프레임으로 묶고 3벤치 창발을 게이트(G4)로 검증하는 것

3.7 정렬 사전학습 init (P50) 게이트 통과 +0.74

항목내용
데이터Places365 500k × pseudo-모달 6종 — depth(추정) · pseudo-LiDAR(depth rasterize) · event(gradient proxy) · AoLP/DoLP(depth→normal→Fresnel proxy) · NIR(luminance+ExG proxy). 전부 유도 프록시임을 meta에 명시
목적함수MultiMAE식 cross-modal masked reconstruction — 한 모달을 가리고 다른 모달로 복원 → 어댑터+트렁크가 모달 대응 구조를 선학습
산출LoRA+트렁크+FPN 가중치만(226 텐서) — 본학습의 초기화로만 사용, 구조 무변경. 이득은 조기 수렴 국면에 집중(매칭 통제 +0.74~+1.38, H22)

4. 학습 vs 추론

추론 시 남는 것 = frozen 백본 + LoRA + 트렁크 + FPN/헤드뿐. 컨트롤러 2종·prototype bank·uni-modal head·M2F-lite·VICReg·재구성 head는 전부 학습 시에만 존재. 따라서 세 벤치의 추론 그래프가 완전히 동일하고, 벤치별로 남는 차이는 학습된 가중치(그리고 λ 궤적 로그)뿐이다.
