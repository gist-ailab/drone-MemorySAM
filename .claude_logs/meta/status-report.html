논문 트랙 (RA-L)

  • 서사: ①조건×모달 상호작용 실재 → ②적응 기제 전 수준 실패 + oracle 상계 → ③작동하는 것은 표현력·학습 신호(단 L 근방 포화) → ④두 벤치 (근)SOTA + 정직한 스코프 공개(대형 백본 전제). 실패 이력이 주장의 증거가 되는 구조.
  • 임계 경로: ReliaDINO 초안(볼트 _paper_submission/) — RBMA 중심 서사가 반증된 상태라 재중심화 리라이트가 최우선. 슬롯 3(MUSES 제출)·5(multi-seed)는 이미 충족.
  • 필요 ablation: RGB-D fair-eval · MUSES RGB-L · C2 순기여 · 시드 분산(seedB 계열).
  • 재현성 규약: test-best 금지 · train/eval 해상도 mismatch 명시 · 3-seed mean±std.
