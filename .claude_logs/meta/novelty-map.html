모델 노벨티 맵 — 무엇이 새로운가

2026-08-24 기준 · 논문(accept) 관점에서 "우리가 주장할 수 있는 것 / 없는 것"을 구분한 단일 문서 · 근거 = 원장(H1~H19)·딥리서치 3축·경쟁 논문 검증

한 장 요약 — 베이스 구조(frozen DINOv3 + 모달별 LoRA)는 노벨티가 아니다(선행 점유). 방어 가능한 신규 주장은 셋: ① P51-CMLC = LoRA 부분공간 안에서의 인코딩-시간 cross-modal 결합(미점유 교집합), ② 소거-증명 체인 = "선택으로는 안 된다"를 오라클+실현성 배터리로 증명한 분석(우리 고유), ③ P50-MAP = frozen 백본 위 어댑터만 정렬 사전학습(얇지만 미점유). 셋 다 성능 게이트 통과가 전제이며 현재 검증 중이다.

0. 베이스 구조 (ReliaDINO 계보) — 노벨티 아님, 출발점

  • 왜 노벨티가 아닌가: "frozen 기초모델 + 모달별 LoRA"는 MLE-SAM(2412.04220)이 동일 벤치(DELIVER·MUSES·MCubeS)에서 선점. 인용 의무.
  • 실적: DELIVER test 54.44±2.21 (best 56.99=시드 outlier, 근SOTA 철회 H18) · MUSES test 79.788(융합계보 1위, 단일제출).
  • 약점: C3가 벤치별로 on/off 다름(축-특이, H8) → "진단-구동 활성화"로 재프레이밍 필요(N3 진행).

1. P51-CMLC — 인코딩-시간 Cross-modal LoRA 결합 on/off 페어 ×2 학습 중

graph LR
  IN["4모달 입력"] --> L1["ViT blocks 1-6
(frozen + 모달별 LoRA)"]
  L1 --> C1["CMLC 결합점 ①
z̃_m = z_m + Σ γ·C·z_k
(r=16 부분공간, +0.11M)"]
  C1 --> L2["blocks 7-12"] --> C2["결합점 ②"] --> L3["blocks 13-18"] --> C3b["결합점 ③"] --> L4["blocks 19-24"]
  L4 --> TR["기존 융합 트렁크 → 헤드"]

핵심: 모달별 LoRA의 저랭크 코드를 인코더 중간(block 6·12·18)에서 서로 섞고, 섞인 표현이 다음 block의 입력이 된다 — 이후 층들이 "남의 센서가 귀띔한 정보"를 반영한 채 계속 인코딩(mid-encoder). fusion 직전 결합(xattn, −2.05 반증)과 구조적으로 다르다.

대비 대상그들의 방식P51의 차이
현행 ReliaDINOLoRA 4개가 완전 고립 → 마지막에 융합인코딩 도중 저랭크 결합
MLE-SAM (2412.04220)frozen SAM + LoRA를 산술 평균평균 대신 학습된 결합 (= 정확한 delta, N2로 동일백본 실측 중)
CrossWeaver (2604.02948, 4개월 선행)full-feature 신뢰도 attention · 학습 SegFormer-B0LoRA 부분공간(16차원 채널)에서만 · frozen 대형 VFM
P49-AIR (우리 반증, H14)RGB-중심 주입 → RGB가 삼킴(γ→0 사망)대칭 결합 + γ init 1.0 → γ 살아있음 실측(0.55, 두 시드 재현)

노벨티 = 3겹 교집합 (각각 단독으론 부족, 교집합이 미점유):

  • ① 결합 위치 = PEFT(LoRA) 부분공간 안 — 조사한 어떤 논문도 어댑터 저랭크 코드 공간에서 cross-modal 상호작용을 안 함 (최근접 CoLA 2604.03314는 VL/AV 이종·2인코더, dense 시각 seg 아님)
  • ② frozen 대형 VFM 위 인코더-중간 결합 — 이 칸은 2026년 초에야 MoBaNet(2모달 RS)·CoLA가 좁게 점유, 3+ 동종 시각 모달 주행 seg는 빈 칸
  • ③ 소거-증명 동기 — "선택은 안 된다"(§3)를 먼저 증명하고 결합을 도출한 논리 사슬 = 우리 고유 분석

현재 상태 (정직): γ는 살아있으나(기제 사용 확인) trainer 지표는 off ≥ on(+0.24~0.74) = 조기 신호 비우호적. 최종 판정 = 완주 legal Δ(on−off) per-condition 분해: ≥+1.5 → A 확장 0~+1.5 → F(지배모달 마스킹) 추가 ≤0 균일 → B 재프레이밍

2. 소거-증명 체인 — 분석 노벨티 (성능과 무관하게 확정된 자산) 완결

"융합을 어떻게 고칠까"가 아니라 "무엇이 안 되는지를 체계적으로 닫은" 체인 — 리뷰어가 "왜 이 구조여야 하나"를 물을 때의 답이자, SOTA-독립 accept 축(분석 기여).

단계실험결과
여지 존재?픽셀별 모달-부분집합 오라클(GT 치팅 상계)+8.5 실재, 16~64px 블록에서도 +2~4.6 = 공간응집 (전역 drop-modality ≈0과 대비 → "전역 잉여 ∧ 국소 상보" 분해)
성격은?독립성 널 + 오차상관 분석여지가 anti-consensus — 다수 모달이 함께 틀린 곳에서 소수 하나가 옳음
잡을 수 있나?no-GT 라우터 3종 (다수결·합의·confidence)전부 음수 (confidence −12.5 최악 = anti-confidence까지) → 추론-시간 선택 전면 폐쇄 (H16)
결론—보완 정보는 실재하나 선택 불가 → 인코딩-시간 결합(P51)만 남음

+ 부수 확정: 믹서 3점 통제(xattn −2.05 / gated-MLP / mean=N2 측정 중) · 백본 스케일링 5점 곡선(S+→7B, H12) · 조건축 oracle +0.2(H4) — 전부 "적응·선택·스케일 축 소거"의 정량 증거.

3. P50-MAP — 모달 정렬 사전학습 finetune 중 (매칭 seed821 대조)

graph LR
  A["Places365 20만 장
(RGB만 있는 일반 사진)"] --> B["pseudo-모달 생성
depth 추정→pseudo-LiDAR→event proxy"]
  B --> C["정렬 사전학습
한 모달 가림→다른 모달로 복원
(masked reconstruction)"]
  C --> D["산출: 길들여진 LoRA+트렁크 가중치"]
  D --> E["본 학습 (구조 100% 동일,
출발점만 교체)"]

핵심: 구조는 안 바꾸고 학습 출발점(초기화)만 바꾼다 — 지금까지 LoRA+트렁크는 타깃 3~4천 장으로 맨땅 학습이었다. VLM 교훈("융합 모듈은 2차, 정렬 사전학습이 1차")의 센서 도메인 이식.

  • 노벨티(얇음, 정직히): 선행(OmniSegmentor 등)은 백본 전체를 사전학습 — 우리는 frozen 백본 위 어댑터+트렁크만 정렬. 이 조합은 미점유이나 단독 논문 기둥으론 약함 → 보조 기여 + "정보 축" 분석.
  • 게이트: legal test − 53.57(무사전학습 매칭시드) ≥ +0.5 → 확장 / ≤0 → 폐기. P51과 직교(구조 vs 초기화)라 동시 판독 가능.

5. 방어 전략 — 리뷰어 반론과 답

반론방어 (실행 상태)
"백본이 80배 커서 이기는 것" (DINOv3-L vs B0)동일백본 ablation: 같은 frozen DINOv3-L에서 CMLC on/off + MLE-SAM 평균(N2 학습 중) + 필요시 CrossWeaver MIB 재구현. 백본 스케일링 5점(S+~7B)으로 "모듈 효과 vs 용량" 분리
"LoRA 조합일 뿐" (조합≠기여)기제 수준 격리: 결합 위치(부분공간 vs full-feature)·γ/C 관여도 실측·param-matched. + 소거 체인이 "왜 이 위치인가"를 증명
"벤치마다 구성이 다르지 않나" (C3 on/off)N3 진단-구동 활성화: class-transfer 붕괴를 자동 탐지해 켜는 원칙적 스위치로 재설계 — 3벤치(DELIVER有/MUSES無/MCubeS 검증 중)에서 진단↔효과 일치 증명
"SOTA 아님"정직 보고(n=5 mean±std — 대다수 경쟁자는 단일런)를 rigor로 전환 + SOTA-독립 accept 축(§2 분석) + 3벤치 일반성(MCubeS 진입)

6. 현재 판정 대기 (이 문서를 바꿀 결과들)
