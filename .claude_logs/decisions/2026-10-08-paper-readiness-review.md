# 논문 준비도 비판 검토 (2026-10-08)

user 질문: "지금 있는 모델로 논문이 나오는가, 어디에 내야 안전한가, Q2noKD 결과를 먼저 봐야 하는가." 외부 검토자로 gpt-6-astra(codex 계정1, 웹 검색, 저장소 읽기 전용)에 근거 자료를 주고 비판 검토를 받았다. 원문 = 잡 스크래치 `astra_review/astra.log`(보존 필요 시 NAS 로 이관), 의뢰서 = `astra_review/brief.md`. 아래는 판정 세션이 검토·확인한 요약이다.

## 1. 결론
- **아키텍처 논문으로는 지금 거절 쪽.** 동결 백본 + 센서별 LoRA + 교차 attention + 열화 학습 + 증류는 각각 선행이 있고, "대칭 융합이 강건성을 만든다"는 구조 기여는 통제 실험이 없어 입증되지 않았다.
- **방어 가능한 주장은 학습 설계 쪽**: "추가 품질·조건·텍스트·depth 감독 없이 결측·열화 두 패스 학습으로 센서 결측 강건성을 높인다." 같은 E1·같은 40에폭에서 결측 15조합 평균 40.01 → 48.06, clean 56.58 → 56.59.
- 결측 평균 우위 +1.56~+2.54(두 재학습 기준선 대비) 중 **저하 폭 차이는 0.72~0.76** 뿐이고 나머지는 clean 출발점 차이. "결측 저항성이 2.5점 개선"이라고 쓰면 안 된다.

## 2. 리뷰어가 먼저 찌를 약점(심각도 순)
1. 구조 효과와 백본·학습 효과 미분리: DINOv3-L vs Swin-T, 커리큘럼 vs 최대 강도 고정(ISSUE-041), 증류 유무가 동시에 다르다.
2. 신규성: 구성요소 조합 이상의 새로움이 없다. "외부 레이블 없음"은 MM SAM-adapter 도 같다.
3. 대표 모델 불명: clean 헤드라인은 E1 200에폭, 강건 수치는 Q2 40에폭 → 같은 체크포인트가 아니다.
4. test 를 후보 채택·기각에 반복 사용(val-best 규칙은 이 문제를 해결하지 못함), 기준선 단일 런.
5. 강건 증거가 DELIVER 에 집중, MUSES 얇은 객체 열세, RGB 부분 결측 비우위, 지연·메모리 미측정.

## 3. 판정 세션이 받아들인 정정
- **10-02 "기준선이 더 강한 열화를 받았으니 비교가 보수적"이라는 해석은 철회한다.** 잘못된 스케줄은 기준선을 불리하게 만들 수 있으므로 보수적이라 말할 수 없다(판정 대장 10-08 정정 행).
- **MUSES DGFusion 은 radar 포함 4센서**, 우리는 3센서 → 헤드라인 표의 "같은 센서 수 1위" 분류는 MUSES 에서 틀렸다. 표 정정 필요(headline.yaml 은 감시 세션 구역이 아니라 생성물이므로 다음 생성 때 반영).
- **세 벤치 동일 구조 여부**: MUSES 헤드라인은 P39.1-rank, E1 은 DELIVER. config·모듈 대응표 없이 "같은 구조"라 쓰지 않는다.
- 증류만 +0.42 → "이득의 1/3 이 증류"라는 기여율 계산은 부적절(상호작용·두 패스 학습량 효과가 섞임, "두 clean 패스·KD 없음" 대조군 없음).

## 4. 결정: Q2 200에폭 3시드 일괄 착수 보류(user 선택지 ③)
순서: ①분리 실험 평가(E1·증류만·열화만·Q2 를 같은 부분집합으로, 0.3~1 GPU-일) → ②필요 시 짧은 추가 시드 → ③공정 기준선(정상 커리큘럼 재학습, CAFuser 먼저) → ④선택한 레시피 장기 1시드 → ⑤나머지 확정 시드. 200에폭 자체는 논문 요건이 아니다.

Q2noKD(열화만) 결과별 결정(사전 등록, 허용폭: clean −0.3·결측 평균 −0.5 이내 = 동급):
| 열화만 결과 | 결정 |
|---|---|
| clean·결측·노이즈 모두 Q2 와 동급 | 증류 없는 단순 레시피 채택(교사 비용 제거), 추가 시드로 확인 |
| 강건 동급, clean 낮음 | Q2 유지, 증류 역할 = clean 손실 억제 |
| clean 동급, 강건 낮음 | Q2 유지, 증류의 강건 기여를 추가 시드로 확인 |
| 둘 다 낮음 | Q2 유지 후보, "상승작용" 주장은 요인 실험 완성 후 |
| 열화만이 더 좋음 | 증류 제거 |
| 시드·축마다 승패 바뀜 | 200에폭 보류, 짧은 추가 시드 |

## 5. 비용 대비 효과 큰 추가 실험(astra 제안, 판정 세션 동의)
1. 분리 실험 강건 평가 완성(학습 없음, 0.3~1 GPU-일).
2. 정상 커리큘럼 기준선 재학습(ISSUE-041 옵션 B, CAFuser 먼저, 3090 약 5~8 GPU-일/모델) — 가장 직접적인 공정성 반론 해소. lab-plan DRN-261002-01 을 idea → 우선 검토.
3. 같은 DINOv3-L 에서 "대칭 교차 attention" vs "RGB 쿼리 전용 교차 attention" 대조(센서별 LoRA·탭·헤드 고정, clean/Q2 각 1~2시드, 약 8~16 A100 GPU-일) — 구조 기여를 주장할 수 있는지 직접 판정. 실패하면 구조 서사 철회.
앞으로 후보 선택은 val 로 하고, 기존 test 기반 탐색은 논문에 탐색적 분석으로 밝힌다.
