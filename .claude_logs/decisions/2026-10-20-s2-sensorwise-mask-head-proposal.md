## 1. 한 문장
세부(where)는 센서별 원 해상도 격자에서 마스크로 그리고, 의미(what)는 동결 파운데이션 백본이 결정한다. A2 의 고해상 특징을 빼지 않고 쓰임을 바꾼다.

## 2. 정의 (바꾼 변수 하나 = 고해상 특징의 쓰임)
- 현행 A2: 고해상 어댑터 출력(센서 합산 공유 스템, hires_adapter.py:183)을 FPN 피라미드에 레벨별 합산(model.py:1368) → dense 픽셀 분류와 질의 마스크(m2f_head.py:202) 양쪽에 흘러듦.
- S2: FPN 합산 제거. 어댑터를 센서별로 돌려 F_s(stride-4) 를 내고, 마스크 로짓만 `mask = membed·m_feat_sem + Σ_s (membed W_s)·F_s`. 클래스 로짓(질의)·dense 경로·Q2 학습·arbiter 불변. 게이트·softmax·스칼라·zero-init 없음.
- off 계약: USE=fpn_sum → A2 와 byte 동일, ENABLE=false → Q2 와 byte 동일.

## 5. 게이트 (사전등록, DRN-261020-03)
- 기준선 A2 같은 시드(s821·s902·s903), DELIVER 40ep, legal v2 test@1024.
- 성공: 3시드 평균 24클래스 Δ ≥ 0 그리고 TrafficLight Δ > 0 그리고 thin4 못 그림 ≤ .35 그리고 test EMM15 Δ ≥ −0.5.
- 반증: 24클래스 Δ ≤ −0.5 → 기각. S2-fused 와 차이 < 0.2 → 노벨티 축소. ep20 val −1.0 → kill.
- 순서: 프로브(학습 0) → 구현·스모크 → s821 S2-sum·S2-fused 먼저 → s902·s903 → S2-x 1시드 → 강건 평가 → 전이.

## 6. 클래스별 어댑터에 대한 판단 (user 질문 2026-10-20)
클래스마다 고해상 어댑터를 따로 두는 것(K 세트)은 (a) 어느 픽셀에 어느 클래스 어댑터를 쓸지 정하는 라우팅이 필요하고(CEFR class-expected routing = 반증 축), (b) 파라미터 K배. 대신 S2 는 이미 클래스 조건부다: 질의 헤드가 class-anchored(P39-V3: 질의 k ↔ 클래스 k)이므로 `(q_k W_s)·F_s` 가 "클래스 k 는 센서 s 의 격자를 얼마나 읽는가"를 학습한다. 즉 클래스별 센서 선호를 어댑터 가중치가 아니라 질의 공간에서 얻는다. 어댑터 자체를 클래스별로 바꾸는 것은 S2-sum 결과를 본 뒤 "클래스 조건부 마스크 임베딩 MLP(질의별 W)" 수준에서만 추가 검토한다.

## 7. 2026-10-22 추가 — 클래스 보완 항(③) 후보와 벤치 교차 조건 (user 채택)
근거 그림(NAS analysis_logs/a2_tl_fp_scenes_20261022): A2 는 포스터·간판(GT=Other)을 한 객체로 또렷이 잡고 클래스 하나(TrafficLight)를 잘못 붙인다. Q2 는 같은 자리를 여러 클래스로 조각내 틀린다. 즉 실패는 '어디' 가 아니라 '무엇' 이며, 질의가 읽는 fused(stride-16, 포스터 ≈ 토큰 4개)에는 포스터와 신호등을 가를 질감이 없다는 가설.
- 원칙 정제: "어디는 픽셀 단위 세부가, 무엇은 **객체 단위로 모은 증거**(의미 토큰 + 마스크 안에서 풀링한 세부)가 정한다". 세부를 픽셀 단위로 분류에 섞는 것(A2 dense 경로)은 오염이고, 객체 단위 풀링은 다른 일이다.
- 후보 ③: `cls = cls_head(q + Σ_s V_s · pool_{mask_q}(F_s))` — 질의 q 의 예측 마스크 안에서 센서별 고해상 특징 F_s 를 평균해 선형 V_s 로 질의에 더한 뒤 클래스 로짓. 게이트·라우팅 없음. S2 마스크 식과 함께 한 모듈.
- 선행 조건(user 2026-10-22): 같은 실패가 MUSES 에도 있는지, 객체 클래스 오라클 여유가 MUSES 에서도 ≥ +1.0 인지(DRN 교차 확인 항목) 확인 후에만 ③ 을 S2 스크린에 넣는다. 여유가 DELIVER 한정이면 ③ 은 주 방법에서 제외.
- 교차 확인 전 단계에서 MUSES 1536 평가의 traffic light 는 FP 가 줄었다(DRN-261016-03: 0.07M→0.05M px) — 해상도 상향과 고해상 경로는 다른 개입이므로 MUSES 4모달 A2 완주 후 재측정이 필요하다.
