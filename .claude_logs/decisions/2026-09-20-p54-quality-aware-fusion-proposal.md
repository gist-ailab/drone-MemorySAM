# P54 후보 — 품질 인지 융합 QAF(Quality-Aware Fusion): 합성 열화로 감독한 품질 토큰이 cross-modal attention 의 key 를 막고, clean 에서는 항등이 되는 융합

> **user 요구(2026-09-20)**: 센서별 LoRA 는 진부하다. 노벨티는 (1) 모달리티별 attention 의 실체와 개선, (2) 첫 입력 RGB 가 열화됐을 때 이를 인지하고 다른 모달을 덜 오염시키는 융합, (3) self-attention·cross-attention 의 조합, (4) 학습 단에서 "열화된 모달인지, 좋은 모달이라 잘 써야 하는지" 를 배우게 하는 방법에서 나와야 한다.
> **이 문서의 답 한 줄**: 융합 노벨티는 clean SOTA 축이 아니라 **"존재하되 열화된 모달" 축**(2503.18445 EMM/RMM/NM 벤치)에서만 성립한다. 우리 계보가 4번 반증한 게이트·bias·재가중은 전부 **품질 신호에 감독이 없었다**는 공통 원인을 갖고, 문헌에서 성공한 사례는 예외 없이 라벨(합성 열화·결측 지시자)로 감독한 것들이다. 그래서 제안 = 합성 열화로 라벨을 만들어 품질 토큰을 감독하고, 그 토큰으로 attention key 를 막되 clean 에서는 항등이 되도록 손실로 고정한다. clean 은 잃지 않고(게이트 Δ ≥ −0.3) 강건 벤치를 딴다(게이트 = EQUISeg 48.22 초과·RMM 손실 절반·NM 고노이즈 ≥ 15).

## 0. 현 구조의 실체 — user 질문 (1)·(3) 에 대한 사실

`semseg/models/reliadino/fusion.py:402-720`(E1 확정 레시피 기준, 코드 확인):

| 단계 | 지금 | 문제(실측) |
|---|---|---|
| 모달 내 self-attention | **없음** | 모달 토큰이 같은 모달의 문맥 없이 곧장 다른 모달에 노출 |
| 모달 간 attention | 모달 i 토큰 = query, **나머지 모달 토큰 전부를 이어 붙인 것** = key/value, 2층·가중치 공유·대칭(순서 불변) | 열화된 모달의 토큰이 **모든 모달의 key 로 무제한 진입** = 오염 경로. 벤치 저자도 같은 진단(GeminiFusion 무제한 교환 → NM 고노이즈 3.30 붕괴, 2503.18445 §4.2.3) |
| 품질 신호 | RBMA bias·출력 게이트·veto 전부 **off**(H2·H3 반증) | 신호가 없으니 오염을 못 막음 |
| 융합 후 | 산술 평균 + 클래스별 라우터 잔차 → gated-MLP 트렁크 | 평균 ≈ gated-MLP(H21), cross-attn 트렁크 −2.05(H17) |
| SAM2 memory attention(RGB 첫 프레임, 나머지 = 메모리) | P8~P28 계보에서 **종결**, 현 모델에 없음 | "첫 입력 RGB 열화가 메모리를 오염" 문제는 현 구조에 없지만, 대칭 구조의 오염 문제는 같은 종류 |

실측으로 본 오염의 크기(우리 E1, DELIVER): 결측(모달 0 채움)은 event·LiDAR ±0.05·RGB+depth 만 −0.37 로 **무해**하지만, **존재하되 절반이 망가진 모달**(RMM r=0.5)은 depth −12.68(val)/−6.01(test)·RGB −3.12/−3.69 로 유해. 즉 현 융합은 "없는 것" 은 넘기고 "있는데 틀린 것" 은 그대로 믿는다.

## 2. 설계 (전 항목 토글 가능 — 어블레이션 분해 보장)

### 2-1. 품질 토큰 헤드 Q (`QAF.QUALITY_HEAD`)
- 모달 m 의 LoRA 출력 토큰(융합 전, 48×48) 위에 학습 가능한 품질 query 1개가 모달 토큰을 attend → 모달 스칼라 η̂_m ∈ [0,1] 과 토큰별 η̂_{m,t}(2층 conv 헤드). 파라미터 ≈ 0.3M/모달. 백본·LoRA 동결 상태에서 먼저 학습(§4 1단계).
- 감독(2605.05439 다중 헤드 형식): presence BCE(0 채움 여부) + severity SmoothL1(존재 조건부, 라벨 = 열화 연산자 파라미터의 정규화값) + 패치 마스크 BCE + UMQ 식 순위 제약(라벨 절대값이 불확실한 구간).
- 학습 열화(정규화 후 주입, 샘플당 모달별 독립 p=0.5, GIML 50/50): 패치 드롭 r~U(0,0.75), 가우시안 블러 σ~U(0,3), 감마 노출 γ∈[0.3,3], 컬러 시프트(RGB), depth 홀·스케일 노이즈, LiDAR 빔 드롭·jitter, event 저해상 다운샘플. **벤치 NM 열화(Gaussian σ + S&P D)는 학습에 넣지 않고 held-out**(ImageNet-C 규칙 1903.12261).

### 2-2. 융합 순서와 key 마스크 F (`QAF.FUSION`)
1. 모달 내 self-attention 1층(가중치 공유) — 새로 추가.
2. 모달 간 set-attention 2층(기존 층 재사용): 모달 i 의 query, key/value = **모든 모달 토큰**(자기 포함, 순서 불변). key 토큰 (m,t) 의 pre-softmax 로짓에 **log(1 − η̂_{m,t})** 를 더한다(η̂=0 → 0 = 항등, η̂→1 → −∞ 마스크). 학습 시 clean 배치에는 L_id = mean(η̂) 로 항등을 명시 제약.
3. 융합 후 평균을 (1 − η̂_m) 정규화 가중 평균으로(토글 `QAF.WEIGHTED_MEAN`); 가중은 η̂ 의 고정 함수이며 학습 파라미터가 아니다(QMF 식, H1 재발 차단).
- 반증된 H2 와의 차이: 신호가 무학습 엔트로피·일치도가 아니라 **합성 라벨로 감독된 η̂**, clean 에서는 손실로 0 에 고정. 반증된 H17 과의 차이: 트렁크 교체가 아니라 기존 2층 위에 순서·마스크만 얹으며 clean 기대치를 0 으로 둔다.

### 2-3. depth-anchor 비대칭 D (`QAF.DEPTH_ANCHOR`, 2단계 카드)
- 지배 모달(depth, 단독 57.17 = 4모달의 85%) 토큰은 cross-attn 을 **우회**해 트렁크로 직행, RGB·event·LiDAR 만 depth 를 key/value 로 attend(IAF pure path). RGB query 에 η̂_RGB 토큰을 concat(CAFuser CA² 의 텍스트 조건 라벨을 합성 라벨로 대체 → 외부 신호 불사용).
- 표적 = RGB 열화 시 depth 경로 오염 차단(벤치 표11 CMNeXt 고노이즈 2.31 붕괴가 방지 대상). F 의 치환 진단(§5) 통과 후에만 착수.

### 2-4. 품질 조건부 잔차 LoRA M (`QAF.RESIDUAL_LORA`, 3단계 카드 — E-LoRA 3갈래 판정 후)
- 공유 LoRA(고정) + 모달별 잔차 LoRA 의 스케일 α_m 을 η̂_m 에서 FiLM 으로 연속 변조(Deweather-MoE 2312.16610 가상 전문가; 이산 라우터 없음 → 게이트 붕괴·후반 붕괴 구조적 회피). 이산 전문가 은행(열화 유형별 잔차, DAME-Net 하드 마스크)은 M 의 변형으로 뒤에.
- 전제: 완주 직전 E-LoRA 3갈래(센서별 r16 / 완전공유 r16 / 공유 r8+잔차 r8) 3시드에서 "공유+잔차" 가 clean 무손실일 때만.

### 2-5. 학습 T (`QAF.TRAIN`)
- **1단계**(품질 헤드 선학습, 약 5 epoch): 백본·LoRA·융합 전부 동결, Q 만 학습. **합격 판정(사전 고정)**: 열화 vs clean 패치 AUROC > 0.9, severity MAE < 0.1, **held-out 열화(Gaussian+S&P)에서도 AUROC > 0.8**. 미달이면 중단(품질 헤드가 "RGB 통계" 만 배운 자명해).
- **2단계**(융합 미세조정, 40 epoch, LR 0.5×): LoRA+융합+Q 학습. 매 배치 두 패스 — (i) clean 패스 CE(상시 유지) (ii) 열화 패스 CE + λ_kd(0.5)·KL(**동결 E1 교사** clean 로짓 ‖ 열화 패스 로짓, T=2) + λ_q(0.1)·품질 손실 + L_id. 완전 결측은 열화의 20% 만(결측은 이미 무해, 표적은 존재-열화). curriculum: severity 상한 0.3→0.6→1.0(10 epoch 단위). 게이트·품질 헤드 fp32.
- 대조군 T′(품질 헤드 없이 교사 증류만 = 문헌 위험 최저): 같은 일정에서 F·Q off. F·Q 의 순기여를 여기서 분리한다.

## 3. 반증 대장 대조표 (제안 전 필수)

| 반증 항목 | 반증 내용 | 이 제안이 같은 함정에 빠지지 않는 이유 | 남는 위험 |
|---|---|---|---|
| H1 학습 게이트 | 과제 손실만으로 학습 → 상수 수렴 | 게이트 값 = 감독된 η̂ 의 **고정 함수**, 학습 파라미터 아님; 학습 데이터에 품질 변동 주입 | η̂ 자체가 자명해로 수렴 → 1단계 합격 판정·치환 검정으로 조기 차단 |
| H2 RBMA additive bias | 무학습 신호, clean 에서 순손해 | 신호 감독 + clean 항등 손실 | clean Δ 가 −0.3 아래면 폐기(게이트) |
| H3 추론 재가중 | 추론 시 후처리 → 유해 | 학습에 포함, 추론 구조 동일 | — |
| H16 내용 기반 라우팅 | no-GT 신호 전부 음수 | 라우터 입력이 내용이 아니라 품질 상태(감독) | M 단계에서만 해당, F 통과 후 착수 |
| H17 cross-attn 트렁크 | drop-in 교체 −2.05 | 트렁크 교체 아님, 기존 2층 위에 순서·마스크 | 순서 변경(self 1층 추가)이 clean 을 흔들 수 있음 → 토글 어블레이션 |
| H15 MIC 마스킹 | EMA 교사 + 마스킹 −1.67 | 교사 동결(E1), clean 패스 CE 상시, 모달 단위 열화 | 두 패스로 스텝 비용 2배 |
| H21 gated-MLP ≈ 평균 | 믹서는 비병목 | 믹서를 바꾸지 않음 | — |
| 모달 잉여(§0.5) | event·LiDAR 무용 | clean 이득을 주장하지 않음; 이득은 강건 축 | 강건 벤치 이득도 depth·RGB 열화에서만 실재할 것 |

falsifiable 예측: (a) T′(증류만)는 RMM 손실을 20~40% 줄이되 NM 고노이즈는 12 이하에 머문다. (b) F+Q 는 NM 고노이즈에서 T′ 보다 ≥ +3. (c) η̂ 셔플 시 clean Δ 는 |0.1| 이하, RMM Δ 는 −2 이상 악화. (a)(b)(c) 중 하나라도 반대로 나오면 "품질 토큰이 열화를 인지해 오염을 막는다" 는 주장을 접는다.

- **주장 문구(권고)**: "first" 보다 실측 주장 — "외부 라벨 없이 합성 열화로 감독한 품질 토큰이 clean 을 잃지 않으면서(Δ ≥ −0.3) 존재-열화 모달의 오염을 막아 강건 벤치 세 축을 올린다". 미확인 위험: MAIL(OpenReview caMnGCyONx)·SSCL(ISPRS 유료) 본문 미열람.

## 6.5 user 결정 (2026-09-20)
- ① 강건 벤치를 포함하되 **DGFusion 성능(clean test 56.71)까지 나와야 하고, 그때 DGFusion 보다 강건해야 한다** → §4 G-clean 상향·G-robust-vs-DGFusion 신설. QAF 는 단독 카드가 아니라 원거리·얇은 객체 회복 카드와 결합한 런으로 판정한다.
- ② "학습 열화가 열화 벤치 이미지를 넣는 게 아니라 modality missing 문제를 푸는 것 아닌지" → 확인 결과(§1-bis) 맞다: 기존 DELIVER 방법의 학습 열화는 전부 **모달 드롭(결측)** 이고, 존재-열화(노이즈·블러·픽셀 손상)를 학습에 넣은 dense seg 선례는 없다. NM 벤치는 clean 학습 모델에 평가만 한다. 우리 제안은 존재-열화를 학습에 넣되 벤치 NM 열화(Gaussian+S&P)는 held-out 으로 둔다.
- ③ MUSES 제출은 user 가 직접(zip 경로 요구), ④ hpca100 미사용 웨이트는 drone_nas 로 이동(검증 이동).

### §1-bis. 확인: 기존 방법의 "학습 열화" 는 무엇인가 (딥리서치 C 표 4·표 2, 2026-09-20)
| 방법 | 학습 시 열화 | 종류 |
|---|---|---|
| CMNeXt·CMX·MAGIC·MAGIC++·Any2Seg·StitchFusion·GeminiFusion·Sigma·MemorySAM·DPLNet | **없음**(resize·flip·color jitter·blur·crop 만) | — |
| CAFuser(MUSES 20%)·MUSES 기준선(20%)·MISS/FPT(모달별 스위치)·AnySeg·RMMSS/RobustSeg·CHARM(취약 모달 편향)·MetaBEV(1/3) | 있음 | **모달 드롭(완전 결측)만** |
| DGFusion·CAFuser(우리 재학습본, DELIVER) | **없음** — 기본값 `RANDOM_DROP=[0.2]*4`(cafuser/config.py:255)를 DELIVER 학습 config 가 `[0,0,0,0]` 으로 덮어씀(configs/deliver/swin/dgfusion_…clde.yaml:34, cafuser_…clde.yaml:29; 저장 config 로 확인). `MODALITIES.AUGMENTATIONS`(CUTMIX·EXTREME·MIXUP·PATCH) 전부 `ENABLED: false`. 켜진 증강 = Resize·Crop·**ColorAugSSD(RGB 에만, 나머지 모달은 항등)**·Flip | 결측 드롭도 열화도 없음 — depth 는 학습 중 한 번도 빠지거나 망가진 적 없음(재학습 세션 코드 확인 2026-09-20) |

| 존재-열화(노이즈·블러·픽셀 손상)를 학습에 넣은 DELIVER/MUSES seg | **0건** | — |
- DELIVER train split 자체에 코너 케이스(MB 600·OE 200·UE 199·LJ 199·EL 200장)가 들어 있어 조건별 열은 "미학습 부식" 이 아니다. 진짜 미학습 열화는 2503.18445 의 zero-fill·Gaussian·S&P 뿐.
- 🔴 공정성 함의(2026-09-20): 기준선의 depth 는 학습 중 교란을 받은 적이 없으므로, 우리가 존재-열화를 학습에 넣고 강건 벤치에서 이기는 것은 "학습 증강 차이" 로 설명될 수 있다. 따라서 G-robust-vs-DGFusion 은 두 행으로 판정한다: (a) 기준선 발표 config 그대로(드롭·열화 없음) (b) **기준선을 우리와 같은 열화 커리큘럼으로 재학습한 행** — 진짜 주장은 (b) 를 이겨야 성립한다. (b) 재학습은 재학습 세션이 복원 킷으로 가능(DELIVER 200k, 약 2일/런).
- 함의: "결측" 은 우리 모델에 이미 무해(±0.05)이므로 결측 드롭 학습은 얻을 것이 없고, 우리가 열어야 할 축은 **존재-열화**다. 이것이 기존 방법과의 차이이자 리뷰어에게 설명해야 할 지점이다.

### §6.6 E-LoRA 3갈래 판정 반영 (2026-09-21)
- 센서별 r16 / 완전공유 r16 / 공유 r8+잔차 r8 은 clean(24클래스)·결측·존재 열화 어디서도 구분되지 않았다(3시드; 유지율 72.4/73.7/74.0%, 갈래 안 시드 범위가 갈래 간 차보다 큼). → §2-4 의 "공유 전문가 고정 + 잔차" 전제는 근거를 잃었고, M(품질 조건부 잔차 LoRA)은 **후순위**로 내린다.
- 남는 사실: RGB 열화 손해는 갈래·시드 무관(−3.6~−4.2), depth 열화 손해는 −6.3~−17.9 로 런마다 다르다. 즉 **depth 의존도의 시드 분산**이 강건성 분산의 출처다. QAF 의 표적을 "depth 토큰의 품질 조건부 마스크 + clean 항등" 으로 좁히고, 게이트에 "3시드 depth 열화 Δ 의 std 절반 이하" 를 추가한다.

## 7. user 결정이 필요한 것

1. 이 제안의 **주 축을 강건 벤치(EMM/RMM/NM)로 두는 것**에 동의하는가 — clean SOTA 축에서는 문헌·실측 모두 이득 근거가 없다.

4. MoE-LoRA 갈래(Q5)는 E-LoRA 3갈래 판정 뒤로 미루는 것에 동의하는가.
