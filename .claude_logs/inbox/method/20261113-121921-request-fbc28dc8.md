## 요청: 브리프 기여 문장 갱신 — "시스템 + 학습 방식 + 분석" 틀 (DRN-261027-01)

출처: 세션 "MMSAM | discussion", user 직접 지시 2026-11-13 "응 브리프 갱신 method에 요청해줘". user 걱정: "contribution 불렛에서 뭘 명시할 수 있는지, high-res path 라도 조금 바꿔서 제안해야 하는 것 아닌가".

### discussion 의 정리(근거 포함)
- 강한 의미의 구조·기법 노벨티는 Access 에 없다: 고해상 경로 = DINOv3 공식 `DINOv3_Adapter` 와 같은 구조(SPM stem·extractor 6개·injector 없음·백본 동결·중간층 4개 resize 합산 — 공식 코드 직접 확인 2026-11-13), 우리 차이는 멀티센서 확장뿐. C2D2 는 파이프라인 단위로만 효과(정확도 유지, val EMM +9.75), 요소별로는 열화 패스만(L5 −9.4), 증류 L6 결론 없음, 물리 열화 L7 기각. 구조 노벨티는 RA-L(inbox 20261113-114717).
- Access 는 "실험이 탄탄한 방법·시스템 + 분석" 틀로 가능하다는 판단(보장 아님). 위험 4개: augmentation 반론(L9 대기) · 큰 백본(DINOv3-B test 53.39 < DGFusion 56.7, DRN-261105-01 대기) · 구성요소 전부 선행 · 제목-증거 불일치.

### 제안 기여 불릿(초안, 측정된 사실만)
1. **C2D2 training scheme**: every batch is used with the original inputs and with sensor-corrupted copies (dropout and sensor-specific degradation), the corrupted pass also distilled from a frozen clean-input teacher. It needs no condition labels and adds no inference cost. It keeps full-sensor accuracy (within run-to-run spread) while raising the average over missing-sensor subsets by 9.8 points; removing the corrupted pass removes this gain. (+ L9 결과에 따라 "unlike single-pass augmentation" 한 구절 추가 여부)
2. **A single multi-sensor model on a frozen vision foundation backbone**, with the DINOv3 high-resolution adapter extended to several sensors, that is the most accurate four-sensor model on the DELIVER, MUSES, and MCubeS test sets and the best under the public missing-sensor benchmark. (val 1위·"모든 표 1위"는 쓰지 않음: StitchFusion val 70.3 > 70.17)
3. **Controlled analysis**: baselines re-trained with the same corruption, released weights re-scored with one evaluation code, sensor dependence per condition, thin structures recovered by the high-resolution path, and failure cases (posters read as traffic lights).

- 대신 **모델은 그대로 두고 "멀티센서 확장"을 측정된 설계로 만드는 ablation** 이 가장 싸다(lab-plan check: 유사 항목 없음):
