## 요청: depth 제거 시 조건별 하락 재측정 — 모든 곡선을 DELIVER test 한 split 으로 (DRN-261027-01, user 지시 2026-11-04)

무엇을 보려는 측정인가: 논문 Fig.6(조건별 depth 의존도) 는 "clean 학습만 한 우리 모델은 DGFusion 처럼 depth 에 크게 의존하고, C2D2 학습을 하면 의존이 크게 줄어든다"를 보인다. 지금 그림에는 두 가지 흠이 있다.
- 우리 곡선은 고해상 경로가 없는 모델(E1, Q2 시드821)로 쟀다. 논문 최종 모델(A2, 고해상 경로 포함)의 값이 없다.
- DGFusion(reproduced) 곡선은 test 에서, 우리 곡선은 val 에서 쟀다.
이번 측정으로 세 곡선을 전부 같은 split·같은 하네스로 맞추고, 최종 모델 곡선을 추가한다. 판정은 필요 없고 측정·보고만 하면 된다.

### 측정 정의 (기존 판정 대장 2026-09-30 행과 같은 방식)
- split: DELIVER **test 1897장**, legal v2 하네스(1024, BS1, native GT, nearest-exact).
- 조건: sun · cloud · rain · fog · night · low exposure(under-exposure) 의 6개. 조건별 mIoU 는 해당 조건 이미지로만 계산한다.
- depth 제거 = depth 입력을 0 으로 채움(다른 센서는 그대로). 하락 = clean mIoU − depth 제거 mIoU (점).

### 대상 모델 (우선순위 순)
1. **A2 = 논문 최종 모델(C2D2 학습 + 고해상 경로)** 3시드(821·902·903). 새 곡선 "Ours, C2D2 training" 이 이 값으로 바뀐다.
2. **E1 = clean 학습만 한 같은 구조(고해상 경로 없음)** — 그림에 쓴 E1 확정(200ep) 체크포인트를 test 로. 가능하면 40ep 3시드 스크린 체크포인트도 함께(학습 길이를 A2 와 맞춘 비교용).
3. Q2(C2D2 학습, 고해상 경로 없음) 3시드 — 여력이 있으면. 고해상 경로가 depth 의존도에 영향을 주는지 확인용.
- DGFusion(reproduced) 는 이미 test 값이 있으므로 다시 잴 필요 없다(판정 대장 2026-09-30 행).
