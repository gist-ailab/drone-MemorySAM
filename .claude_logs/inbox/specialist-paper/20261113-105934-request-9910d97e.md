## 요청: 정확도의 출처를 초록·서론에 명시 (DRN-261027-01)

출처: 세션 "MMSAM | discussion", user 직접 지시 2026-11-13 "셋 다 진행해줘"(그중 '정확도 출처 명시'). 제목은 user 가 더 논의한 뒤 바꾼다 — 이번 요청에서 제목은 건드리지 말 것.

### 문제
- 현재 초록은 "We propose C2D2 … We train with it a fusion model … reaches 57.7 …" 순서라, C2D2 가 정확도를 올린 것처럼 읽힌다.
- 측정(tab:abl_robust, 이미 원고에 있음): C2D2 없음 → 있음에서 test clean 56.40 → 56.59(+0.19, 시드 폭 안), MCubeS 59.89 → 59.78(−0.11). val EMM 47.12 → 56.87(+9.75). 고해상 경로 +1.15(56.59 → 57.74, C2D2 위에서).
- 즉 정확도는 모델(동결 파운데이션 백본·교차 attention·고해상 경로)에서, C2D2 는 **정확도를 잃지 않고 센서 결손 시 성능을 지키는** 쪽에서 온다.

### 요청 문장 방향(user 의 논지: "우리 구조가 성능도 높은데 센서가 빠져도 성능이 잘 유지된다")
- 초록·서론 P4·기여 ②: "The model is accurate with all sensors (57.74 …), and the C2D2 training keeps this accuracy while raising the average over missing-sensor subsets by 9.8 points (validation, Table abl_robust); removing the degraded pass removes this gain (L5)."
- **증류가 그 효과를 낸다고 쓰지 않는다**(L6 결론 없음). 파이프라인 전체(C2D2 = 두 패스 + 열화 + 교사 증류)의 효과로만 쓰고, 요소별로는 열화 패스만 측정된 효과가 있다는 현재 서술(4_method.tex:55) 유지.
- "clean inputs" 를 처음 쓸 때 "원래 데이터셋 샘플(악천후·야간 장면 포함), 인위 손상 없음" 으로 한 줄 정의.
- 고해상 경로 단독 이득은 2×2 빈칸(DRN-261112-04, FU-10) 결과 전까지 "C2D2 를 쓴 모델 위에서 측정" 이라고만 쓴다.
- 백본 체급: 비용표 DINOv3-B 행(test 53.39 < DGFusion 56.7)과 결측 벤치 비교(MAGIC = MiT-B2)를 고려해, 한계 절에 "정확도 우위의 상당 부분은 큰 동결 백본에서 온다" 를 한 줄 명시하는지 확인(DRN-261105-01 결과 대기 중이면 todo).
