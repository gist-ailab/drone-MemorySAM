## 2. 두 통제의 해석

**2a. 입도 스윕 — 회수 여지는 공간적으로 응집돼 있다(핵심 양성 신호).** Δ가 픽셀 +8.66에서 완만히 감소하되 **block16에서 +4.09~4.62, block64(≈12×12 블록/이미지)에서도 +1.93~2.82로 살아남는다.** 픽셀 노이즈였다면 16px에서 <1로 붕괴했어야 한다(사전등록 폐쇄 조건). 붕괴하지 않음 = **회수 가능한 픽셀이 공간적으로 뭉쳐 있다** = 패치 단위 라우터가 원리상 잡을 수 있는 구조. block16 Δ≥2.0(사전등록 "구조 실재" 임계) **충족**.

**2b. 널 — 내 게이트 부등호가 거꾸로였다(2차 스펙 오류, 인정).** 널 +32/+44 ≫ 관측 +8.66. 나는 "관측≫널→구조, 관측≈널→폐쇄"로 등록했으나, **독립 셔플은 union을 관측보다 구조적으로 부풀린다**(무상관 예측기 15개는 정답영역이 덜 겹쳐 union이 커짐 → 오라클이 GT를 거의 전역에 심음 → Δ 폭증). 즉 널-as-built은 "뺄 수 있는 팽창 바닥"이 아니라 **독립 가정 상한**이다. 올바른 브래킷:
  - 완전상관 바닥(단일 예측기 15중복, union 추가이득 0) = **Δ 0**
  - 독립 상한(널) = **+32/+44**
  - **관측 +8.66 = 그 사이 ~27% 지점.**
  → 관측이 0보다 유의히 큼 = **부분집합 상보성 실재**(복권 아님). 관측이 널보다 훨씬 작음 = 부분집합들이 **같은 픽셀에서 함께 틀린다**(양의 오차상관, thin-class 경계 추정). 상보성은 실재하되 독립과는 거리가 멀다.

**두 통제 종합**: +8.66은 (i) 통계적 복권 팽창이 아니고(널 브래킷상 27%=실재 상보성), (ii) 공간적으로 응집돼 있다(입도 스윕). → **"픽셀 노이즈/팽창이라 축 폐쇄"는 기각.**

## 3. 판정

1. **spatial×modality 축은 닫히지 않았다.** GT-회수 가능한 공간응집 상보성이 실측으로 확인됨(block16 +4.1~4.6, block64에서도 +1.9~2.8).
2. **단 사전등록 게이트는 어느 분기에도 깨끗이 안 맞았다** — 입도 절반(block16≥2)은 충족, 널 절반(관측≫널)은 **스펙 오류로 무효**. 이 프로브에서 내 2번째 스펙 오류다(1차=Δ<0.3 사전확률, 2차=널 부등호 방향). 절반만 발화한 게이트를 "라우터 정당화"로 체리픽하지 않는다.
3. **아직 미해결 = 입력-실현성.** 위는 전부 **GT-회수** 상계(입도 스윕도 GT로 블록 선택). "입력만 보고(GT 없이) 그 블록 선택을 맞힐 수 있는가"는 미측정 — 널이 이걸 재려다 스펙 오류로 실패했다. **이게 게이트 착수의 진짜 선행조건.**

## 4. 다음 = 실현가능(no-GT) 라우터 하한 (#15, 캐시 전용 우선)

**게이트 만들기 전 마지막 값싼 관문**: 캐시(argmax맵)만으로 계산되는 **no-GT 라우터**가 오라클 여지의 유의미분을 잡는가.
- **캐시 전용(즉시, GPU 0)**: ① 픽셀/블록 **다수결 앙상블**(15부분집합 mode) Δ vs full ② 블록별 "합의(다수결)에 가장 부합하는 부분집합" 커밋 Δ vs full. 둘 다 GT 불사용=실현가능.
- **forward 재실행 필요(차선)**: per-subset **confidence/entropy**(max-softmax) 기반 블록 선택 — 캐시가 argmax만 보유해 재추론 필요(원 프로브급 비용). 캐시 전용이 애매할 때만.

**사전등록 게이트(#15)**: block16에서 **어느 no-GT 변형이든 Δ ≥ +1.0 → 입력-실현성 확인 → 학습 게이트 착수(신 실험 세대, user GO + GPU 필요)** / 전부 **< +0.5 → 값싼 실현신호 부재 → 학습 게이트가 유일한 결정적 검증**(비용 대비 user 판단). 주의: no-GT 라우터 실패는 학습 게이트 실패를 **증명하지 못함**(하한이라 비대칭) — 음성이면 폐쇄가 아니라 "값싼 길 없음".

## 5. 원장/서사 반영

- **H16**: ⏳ 개방 유지 — "GT-회수 공간응집 상보성 확인, 입력-실현성 #15 대기". 폐쇄도 라우터 정당화도 아님.
- **종합 §1 단서 유지 강화**: 조건축은 타이트 상계(+0.2)로 닫혔으나 **공간축은 GT-회수 여지 +4(block16)로 열려 있다** — 실현성이 관건.
- **논문 회수(실현성 결과와 무관하게 확정)**: **"전역 모달 잉여(drop≈0) ∧ 국소 모달 상보(16~64px에서 +2~4.6)"** = 모달 잉여를 전역/국소로 분해하는 실측. 게다가 오차상관 구조(부분집합이 thin-class 경계에서 함께 실패)도 정량화됨. 이건 게이트 성패와 독립하게 서사 자산.
