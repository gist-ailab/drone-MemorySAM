# Spatial×Modality 축 종결 (H16) — 선택-불가 확정, 인코딩-시간으로 재조준 (2026-08-20)

- #15b 게이트(block16 ≥+1.0 → 실현성 확인 / <+0.5 → 신호 소진): **압도적 후자.** confidence는 미달이 아니라 **셋 중 최악**.

## 2. 판정 — 선택(selection)은 죽었다

**H16 = spatial×modality 라우팅/선택 축 실용적 종결.** GT-회수 여지(+8.5)는 실재하나, **realizable한 어떤 no-GT 선택 신호로도 접근 불가**하다:
- 여지는 **anti-consensus**(다수가 틀린 곳에서 소수가 옳음 — #14 널) **AND anti-confidence**(옳은 소수 모달이 고신뢰가 아님, 고신뢰는 오히려 OOD-오답).
- 즉 옳은 모달이 **합의로도 신뢰도로도 표시되지 않는다** → 자연스러운 입력 단서 둘 다에 **직교**. 학습 게이트가 이길 가능성 = 이 둘과 무관한 비자명 신호를 발견해야 = 매우 낮은 사전확률.
- H1(학습 게이트)·H3(추론 재가중)와 정합 — **추론-시간 모달 선택/재가중 계열 전면 폐쇄** 재확인.

## 3. 🔑 그러나 이것은 "인코딩"이 아니라 "선택"만 죽인 것

**결정적 구분**: 위 실험들은 전부 **이미 인코딩된 고정 per-modal 특징 위에서의 선택/라우팅**을 쟀다. 닫힌 것은 그 축이다. **특징을 어떻게 인코딩하는가**(인코딩-시간 상호작용 + 학습-시간 신호)는 이 결과가 닫지 못한다:

| 축 | 상태 |
|---|---|
| 추론-시간 모달 **선택/게이팅/재가중** (고정 특징 위) | 🔴 **종결** (H1·H3·H16, 오라클-도달 불가) |
| 인코딩-시간 **cross-modal 결합**(N2, 어댑터 부분공간 상호작용) | ⚪ 미검 — 특징을 *선택*이 아니라 *생성* |
| 학습-시간 **강제 신호**(C3 prototype / 지배모달 마스킹 + 소수 hard-pixel aux) | 🟢 부분 실증(C3=DELIVER SOTA-근접 기여) |

→ 3주 캠페인 + 이 종결이 방향을 **수렴**시킨다: **선택을 버리고, 인코딩-시간 결합 + 학습-시간 강제로 소수 신호가 살아있는 특징을 만든다.** (딥리서치 축2 처방과 정합: 소수 보존은 아키텍처 대칭이 아니라 학습 신호로 온다 — MoBaNet MCRM.)

## 4. 논문 가치 — 음성이 방법의 동기가 된다

이 종결은 손실이 아니라 **서사 자산**이다: *"모달-보완 정보는 국소적으로 실재하나(오라클 +8.5, 공간응집) 추론-시간 선택으로는 도달 불가함을 오라클+실현성 배터리(3신호)로 소거 증명 → 따라서 인코딩-시간 결합 메커니즘이 필요하다."* 음성 결과가 제안 메서드의 **동기**가 되는 구조(MM-SAM-adapter식 분석-우선 accept 패턴 + 메서드).

## 5. 전략 함의 (A/B/하이브리드 결정에 직결)

- **선택형 모듈(라우터/게이트/MoE)을 짓는 방향 = 폐쇄.** N2를 "라우팅"으로 설계하면 안 됨.
- **N2를 "인코딩-시간 cross-modal 결합"으로** 설계하면 이 종결에 저촉 안 됨 — 오히려 그 동기가 됨. **하이브리드 권고 강화**: 최소 N2(어댑터 부분공간 인코딩-결합, 학습 시 지배모달 마스킹) → 동일 백본에서 MLE-SAM 평균융합 대비 이득만 먼저 확인.
- C3 축-특이성(DELIVER on / MUSES off) 문제는 "진단-구동 활성화"로 재프레이밍(공통 과제).
