\begin{abstract}
Multi-modal semantic segmentation from unmanned surface vehicles must cope with severe sensor degradation---particularly RGB cameras at night---while exploiting complementary thermal and LiDAR information.
MemorySAM recently showed that SAM2's temporal memory mechanism can be repurposed for cross-modal fusion by treating each modality as a sequential frame.
However, this sequential design has a structural vulnerability: the first modality (typically RGB) initializes the memory bank, and all subsequent modalities attend to it via cross-attention.
When RGB is degraded at night, its low-quality features pollute the shared memory, corrupting the cross-modal attention for thermal and LiDAR.
We propose \emph{Quality-Aware Memory Gating} to address this memory pollution.
During training, a frozen copy of SAM2's decoder independently segments each modality to produce per-pixel cross-entropy maps against the ground truth, yielding spatial quality targets.
A lightweight convolutional gating network (${\sim}$12.5K parameters) learns to predict these quality maps from the encoded features alone, and at inference the predicted maps spatially modulate memory features before they enter the bank---preserving high-quality regions while suppressing degraded ones---without additional decoding cost.
Combined with Soft Mixture-of-Experts LoRA for modality-adaptive encoding and aggressive night-simulation augmentations, we validate our approach on the MULTIAQUA benchmark for daytime-to-nighttime maritime segmentation.
