Our method builds on MemorySAM~\cite{chen2025memorysam}, which adapts SAM2~\cite{ravi2024sam2} for multi-modal semantic segmentation by treating each modality as a sequential frame processed through the memory-based tracking pipeline.
We retain this sequential processing paradigm and introduce quality-aware memory gating to address the memory pollution problem.
Our pipeline operates in five phases: given $M$ input modalities (RGB, thermal, LiDAR), (1) each modality is encoded by SAM2's frozen backbone with Soft-MoE LoRA layers; (2) a cross-modal fusion head produces relative modality weights; (3) the modality features are modulated by uncertainty-aware weights before entering the tracking step; (4) a spatial quality gating network modulates the resulting memory features before they are stored in the memory bank; and (5) the per-modality outputs are fused using the relative weights.


\subsection{Soft-MoE LoRA}
\label{sec:soft_moe_lora}

We keep SAM2's image encoder frozen and inject low-rank adaptation matrices into the query and value projections of each attention block, following the standard LoRA~\cite{hu2022lora} formulation.
Rather than using a single pair of low-rank matrices, we maintain $N$ expert pairs $\{(\mathbf{A}_i, \mathbf{B}_i)\}_{i=1}^{N}$, where $\mathbf{A}_i \in \mathbb{R}^{d \times r}$ and $\mathbf{B}_i \in \mathbb{R}^{r \times d}$, with $r$ being the LoRA rank and $d$ the feature dimension.

Following the Soft Mixture-of-Experts formulation~\cite{puigcerver2024softmoe}, instead of selecting the top-$k$ experts via hard routing~\cite{zhu2024moe, shazeer2017moe}, we compute a softmax-weighted combination over all experts for each input token $\mathbf{x}$:
\begin{equation}
  \Delta \mathbf{x} = \sum_{i=1}^{N} \alpha_i(\mathbf{x}) \cdot \mathbf{B}_i \mathbf{A}_i \mathbf{x},
  \quad \alpha_i(\mathbf{x}) = \frac{\exp(g_i(\mathbf{x}))}{\sum_{j=1}^{N} \exp(g_j(\mathbf{x}))},
  \label{eq:soft_moe}
\end{equation}
where $g(\mathbf{x}) = \mathbf{W}_g \mathbf{x} + \mathbf{b}_g$ is a lightweight gating network with $\mathbf{W}_g \in \mathbb{R}^{N \times d}$.
The output of the original QKV projection is augmented as $\mathbf{q} \leftarrow \mathbf{q} + \Delta \mathbf{q}$ and $\mathbf{v} \leftarrow \mathbf{v} + \Delta \mathbf{v}$.
When the number of experts $N$ is small (\eg, $N{=}3$), hard top-$k$ routing with $k{=}2$ permanently disables one expert per token; soft gating avoids this by ensuring gradient flow to every expert at every step.
We use $N{=}3$ experts and $r{=}4$ throughout our experiments.


\subsection{Cross-Modal Fusion with Dual-Path Weighting}
\label{sec:cross_modal}

\noindent\textbf{Cross-modal scoring.}
In addition to the memory-level quality gating described in \cref{sec:quality_gating}, we employ a cross-modal fusion head for output-level modality weighting.
Rather than scoring each modality independently, which can lead to degenerate solutions when all scores collapse to similar values, we jointly compare all modality features to produce relative weights.
Given backbone feature maps $\{\mathbf{F}_i\}_{i=1}^{M}$, each is compressed by a shared network into a compact vector:
\begin{equation}
  \mathbf{z}_i = \operatorname{ReLU}(\mathbf{W}_c \cdot \operatorname{GAP}(\mathbf{F}_i) + \mathbf{b}_c),
  \label{eq:compress}
\end{equation}
where $\operatorname{GAP}$ denotes global average pooling and $\mathbf{W}_c \in \mathbb{R}^{h \times C}$ are shared weights.
The compressed vectors are concatenated and passed through a comparison MLP to produce modality weights:
\begin{equation}
  \mathbf{l} = \psi([\mathbf{z}_1; \mathbf{z}_2; \ldots; \mathbf{z}_M]),
  \quad w_i = \frac{\exp(l_i / \tau)}{\sum_{j=1}^{M} \exp(l_j / \tau)},
  \label{eq:cross_modal}
\end{equation}
where $\psi$ is a two-layer MLP and $\tau$ is a temperature parameter.
We initialize the output layer of $\psi$ to zero, ensuring uniform weights $1/M$ at the start of training for stable initialization.

\noindent\textbf{Uncertainty-Aware Memory Modulation (UAMM).}
Before each modality's features enter SAM2's memory-augmented tracking step, we modulate them using max-normalized weights:
\begin{equation}
  \hat{w}_i = \frac{w_i}{\max_{j} w_j + \epsilon},
  \quad \hat{\mathbf{f}}_i^{(k)} = \hat{w}_i \cdot \mathbf{f}_i^{(k)}, \quad \forall k,
  \label{eq:uamm}
\end{equation}
where $\mathbf{f}_i^{(k)}$ are the multi-scale vision features for modality $i$ and $\epsilon = 10^{-8}$.
The max-normalization ensures that the highest-scoring modality always receives $\hat{w} = 1.0$ (no attenuation), while other modalities are scaled down proportionally.

The modulated features are then processed by SAM2's tracking step, where the first modality initializes the memory and subsequent modalities attend to it via cross-attention, enabling cross-modal feature exchange through SAM2's built-in memory attention mechanism.

\noindent\textbf{Adaptive Mask Fusion (AMF).}
After obtaining per-modality mask predictions $\mathbf{o}_i$ from the tracking loop, we fuse them using the raw softmax weights:
\begin{equation}
  \mathbf{o}_\text{fused} = \sum_{i=1}^{M} w_i \cdot \mathbf{o}_i,
  \label{eq:amf}
\end{equation}
where $w_i$ are the softmax weights from \cref{eq:cross_modal}.
This dual-path design---max-normalized for UAMM, raw softmax for AMF---serves complementary purposes: UAMM requires absolute preservation of the best modality's feature magnitude, while AMF requires relative weighting proportional to estimated quality.


\subsection{Quality-Aware Memory Gating}
\label{sec:quality_gating}

The cross-modal fusion head and UAMM modulate the vision features \emph{before} the tracking step, but the memory features generated \emph{after} the tracking step are stored in the memory bank without any quality-based filtering.
When a degraded modality (\eg, RGB at night) produces low-quality memory features, subsequent modalities attend to these corrupted features through SAM2's cross-attention mechanism, propagating errors across the entire fusion pipeline.
We address this by introducing a spatial quality gating module that modulates memory features before they enter the bank.

\subsubsection{Teacher: Per-Modality Decoder Quality Assessment}
\label{sec:teacher}

During training, we generate spatial quality targets by independently decoding each modality's features through SAM2's decoder \emph{without} cross-modal memory.
For each modality $m$, the encoded vision features $\mathbf{f}_m$ are passed through SAM2's mask decoder in single-frame mode, bypassing the memory bank entirely:
\begin{equation}
  \hat{\mathbf{y}}_m = \operatorname{Decoder}(\mathbf{f}_m; \emptyset),
  \label{eq:teacher_decode}
\end{equation}
where $\emptyset$ denotes an empty memory bank and $\hat{\mathbf{y}}_m \in \mathbb{R}^{B \times C \times H \times W}$ are the per-modality logits with $C$ semantic classes.
The per-pixel cross-entropy against the ground truth $\mathbf{y}^*$ provides a spatial error map:
\begin{equation}
  \mathcal{E}_m(p) = -\sum_{c=1}^{C} \mathbf{y}^*_c(p) \log \hat{\mathbf{y}}_{m,c}(p),
  \label{eq:ce_map}
\end{equation}
where $p$ indexes spatial positions.
This error map is converted into a quality target:
\begin{equation}
  \mathbf{q}^*_m = \operatorname{downsample}\bigl(\exp(-\mathcal{E}_m)\bigr) \in [0, 1]^{H' \times W'},
  \label{eq:quality_target}
\end{equation}
where $H' \times W'$ matches the feature map resolution.
Positions where the modality produces accurate predictions yield quality values near 1.0, while positions with high error yield values near 0.

This teacher signal has two important properties compared to confidence-based alternatives:
\textbf{(i)} It measures \emph{correctness} against the ground truth, not merely confidence---a modality that is ``confidently wrong'' (\eg, LiDAR predicting water where there is sky) receives low quality.
\textbf{(ii)} It captures \emph{structural} modality limitations that persist even as the model converges: LiDAR inherently cannot distinguish sky from water, so its quality target for sky regions remains low throughout training, providing a non-diminishing supervision signal.

The teacher decoder is frozen during this process and adds no gradient computation cost.

\subsubsection{Student: Spatial Quality Gating Network}
\label{sec:student}

A lightweight convolutional network predicts the spatial quality map from the encoded features:
\begin{equation}
  \hat{\mathbf{q}}_m = \sigma(\mathcal{G}(\mathbf{f}_m^{(0)})) \cdot (1 - q_\text{min}) + q_\text{min},
  \label{eq:quality_pred}
\end{equation}
where $\mathbf{f}_m^{(0)}$ is the highest-resolution FPN feature, $\sigma$ is the sigmoid function, $q_\text{min} = 0.1$ prevents complete zeroing of memory features, and $\mathcal{G}$ is a three-layer CNN:
\begin{equation}
  \mathcal{G}: \operatorname{Conv}_{3 \times 3}(C_\text{in}, 64) \to \operatorname{ReLU} \to \operatorname{Conv}_{3 \times 3}(64, 64) \to \operatorname{ReLU} \to \operatorname{Conv}_{1 \times 1}(64, 1).
  \label{eq:gating_net}
\end{equation}
The final layer's bias is initialized to $+1.0$, yielding $\sigma(1.0) \approx 0.73$, so that all memory features pass through with moderate gating at the start of training (optimistic initialization).
The network contains ${\sim}$12.5K parameters.

\subsubsection{Memory Modulation}
\label{sec:mem_mod}

After each modality's tracking step, SAM2's memory encoder produces memory features $\mathbf{m}_i$ to be stored in the bank. We apply the predicted quality map before storage:
\begin{equation}
  \tilde{\mathbf{m}}_i = \mathbf{m}_i \odot \operatorname{resize}(\hat{\mathbf{q}}_i),
  \label{eq:mem_mod}
\end{equation}
where $\odot$ denotes element-wise multiplication with spatial broadcasting, and $\operatorname{resize}$ adjusts the quality map to match the memory feature resolution via bilinear interpolation.
The gated memory $\tilde{\mathbf{m}}_i$ is then stored in the memory bank for subsequent modalities to attend to.

This design has a direct effect on the cross-modal attention of later modalities.
Consider a nighttime scene where RGB is processed first (frame index 0):
the quality gating network suppresses degraded RGB regions (\eg, sky and water where RGB captures near-zero values), so when LiDAR (frame index 1) and thermal (frame index 2) attend to the memory bank, they receive attenuated contributions from RGB's weak regions while retaining information from regions where RGB remains informative.
Conversely, LiDAR's quality map suppresses sky regions (where LiDAR has no information) but preserves object regions (where LiDAR excels), allowing thermal to selectively leverage LiDAR's strengths.


\subsection{Training Objectives}
\label{sec:training}

Following MemorySAM~\cite{chen2025memorysam}, we use a Semantic Prototype Memory Module: for each class $c$, a global prototype $\mathbf{p}_c$ is maintained via exponential moving average (momentum $= 0.8$), and the prototype loss is $\mathcal{L}_\text{proto} = \text{MSE}(\hat{\mathbf{p}}, \mathbf{p})$.
The quality gating loss is the binary cross-entropy between the predicted quality logits and the teacher target:
\begin{equation}
  \mathcal{L}_\text{gate} = \frac{1}{M} \sum_{m=1}^{M} \operatorname{BCE}(\mathcal{G}(\mathbf{f}_m^{(0)}),\; \mathbf{q}^*_m),
  \label{eq:gate_loss}
\end{equation}
where ignore-class pixels (label 255) are excluded from the loss computation.
The total training loss is:
\begin{equation}
  \mathcal{L} = \mathcal{L}_\text{OHEM} + \mathcal{L}_\text{proto} + \lambda_\text{gate} \mathcal{L}_\text{gate},
  \label{eq:total_loss}
\end{equation}
where $\mathcal{L}_\text{OHEM}$ is the Online Hard Example Mining cross-entropy loss and $\lambda_\text{gate}$ is a weighting coefficient.
The cross-modal fusion head is trained end-to-end through the segmentation objective without additional supervision.
The teacher decoder is frozen, so the quality gating loss gradient flows only through the student gating network.
