\section{Experiments}
\label{sec:experiments}

\subsection{Dataset and Setup}

\noindent\textbf{Dataset.}
We evaluate on the MULTIAQUA dataset~\cite{muhovic2025multiaqua}, which provides synchronized RGB, thermal, and LiDAR data captured from unmanned surface vehicles.
The dataset contains four semantic classes: static obstacle, dynamic obstacle, water, and sky.
Models are trained on daytime data and evaluated on both a daytime validation set and a nighttime test set, where RGB quality degrades significantly.

\noindent\textbf{Implementation details.}
We use SAM2 (Hiera-based backbone) as the foundation model with LoRA rank $r{=}4$ and $N{=}3$ Soft-MoE experts.
All images are resized to $1024 \times 1024$.
We train for 200 epochs with AdamW optimizer (learning rate $6 \times 10^{-4}$, weight decay $0.01$) using a warmup-polynomial learning rate schedule (10 warmup epochs, power $0.9$).
The batch size is 1 per GPU with gradient accumulation, and we use Online Hard Example Mining (OHEM) cross-entropy loss with the prototype segmentation loss (\cref{sec:proto_loss}).
SAM2's image encoder is frozen; only the Soft-MoE LoRA layers, confidence head, prompt encoder, and mask decoder are trained.
Training is conducted with PyTorch DDP on NVIDIA GPUs.

\noindent\textbf{Evaluation metric.}
We report mean Intersection-over-Union (mIoU) averaged over the four semantic classes.
